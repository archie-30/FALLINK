# INKFALL

3D 手繪風射擊 × 牌組構築遊戲。整個世界像是用鋼筆和鉛筆畫在筆記本紙上，以 Three.js 製作，不需要任何建置步驟。

## 線上遊玩

https://archie-30.github.io/project-unknow-pB/

（需先在 GitHub 開啟 Pages，推送到 `main` 後會自動部署。）

## 操作方式

### 桌機

| 按鍵 | 功能 |
| --- | --- |
| W A S D／方向鍵 | 移動 |
| 滑鼠 | 瞄準 |
| 滑鼠左鍵（按住） | 射擊 |
| Space／滑鼠右鍵 | 衝刺 |
| 1–4 | 出對應位置的卡牌（瞄準滑鼠位置） |
| 點擊卡牌 | 無目標卡直接出牌；需要目標的卡進入瞄準模式，再點戰場確認 |
| 拖曳卡牌到戰場 | 指定位置／方向出牌（地面會顯示虛線預覽） |
| 拖曳卡牌到棄牌堆 | 棄掉這張牌（1 秒後補牌） |
| 拖曳「鉛筆牆」到戰場 | 按住不放在地上畫出牆的路徑，放開即長出牆 |
| Esc／右鍵 | 取消瞄準 |
| Tab | 查看牌組（抽牌堆／棄牌堆，遊戲暫停） |
| F2 | 切換畫質（低／中／高） |
| F3 | 顯示除錯資訊（FPS、繪製呼叫、三角形數） |
| H | 隱藏／顯示左下角按鍵說明 |
| Esc／P | 暫停（Esc 在瞄準卡牌時為取消瞄準） |

### 平板（觸控）

| 操作 | 功能 |
| --- | --- |
| 左半螢幕拖曳 | 虛擬搖桿移動 |
| 右半螢幕拖曳 | 瞄準並自動射擊 |
| 右下角「衝刺」按鈕 | 衝刺 |
| 點卡牌 | 自動瞄準出牌 |
| 拖曳卡牌到戰場 | 指定位置／方向出牌 |
| 拖曳卡牌到棄牌堆 | 棄掉這張牌 |
| 拖曳「鉛筆牆」到戰場 | 手指不放在地上畫出牆的路徑 |
| 點抽牌堆 | 查看牌組 |
| 右上角「暫停」按鈕 | 暫停 |

請橫向持握裝置。第一次觸碰時會嘗試進入全螢幕。

### 選單與設定

- 主選單：開始、設定、圖鑑（全部卡牌與敵人說明）。
- 設定：音量、畫質（低／中／高）、震動強度、動態減少、顯示 FPS，會自動儲存在瀏覽器。
- 畫質「低」會降低解析度、關閉紙紋與角色粗外框，適合效能較弱的裝置；平板預設為「中」。

### 整局流程

- 一局共 3 幕，每幕 5 頁（4 個戰鬥房間＋1 個頭目房間）。
- 清除所有波次的敵人後，從 3 張卡中選 1 張加入牌組（可跳過）。擊敗頭目回復 4 點生命。
- 死亡即結束本局，顯示結算畫面後可重新開始。

### 敵人

| 敵人 | 行為 |
| --- | --- |
| 塗鴉兵 | 走位並射出單發紅色子彈 |
| 墨團 | 跳躍接近，死亡時分裂成兩隻小墨團 |
| 圓規手 | 保持距離，發射環狀彈幕 |
| 橡皮怪 | 衝撞玩家，會擦掉玩家畫的牆 |
| 摺紙鳥 | 在空中盤旋，突然俯衝 |
| 巨型墨瓶（頭目） | 螺旋彈、扇形彈、環狀彈、丟出減速墨漬、召喚墨團；背後紅色裂縫受到三倍傷害 |

### 墨水與卡牌

- 擊中敵人與擊殺會累積墨水（上限 10），出牌需要消耗墨水。
- 手牌 4 張，出牌 1 秒後補牌；抽牌堆用完會自動洗牌 2 秒，期間無法出牌。

網址加上 `?deck=all` 可以用全部 15 張卡作為牌組（測試用）；`?seed=數字` 可固定洗牌順序。

網址加上 `?quality=low`、`?quality=mid` 或 `?quality=high` 可以強制指定畫質。

## 本機執行

遊戲使用 ES modules，必須透過本機伺服器開啟，不能直接雙擊 `index.html`。

```
python -m http.server 8000
```

接著開啟 http://localhost:8000/

平板測試：電腦與平板連同一個 Wi-Fi，在平板瀏覽器開啟 `http://<電腦的區網 IP>:8000/`。
