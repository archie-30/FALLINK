# INKRAGE

3D 手繪風射擊 × 牌組構築遊戲。整個世界像是用鋼筆和鉛筆畫在筆記本紙上，以 Three.js 製作，不需要任何建置步驟。

## 線上遊玩

https://archie-30.github.io/INKRAGE/

（需先在 GitHub 開啟 Pages，推送到 `main` 後會自動部署。）

請橫向持握裝置。手機等小螢幕上整個介面會依畫面大小等比例縮小，描邊也會自動變細，避免角色糊成一片。每次切換成觸控操作時會跳出提醒：觸控功能仍在優化中，建議使用鍵盤滑鼠；提醒需倒數 3 秒後才能按「我知道了」關閉（開啟上帝視角時不用等）。第一次觸碰時會嘗試進入全螢幕。行動裝置若持續不順（低於約 42 FPS），遊戲會自動降低畫質。

### 模式與成長

- **關卡模式**：3 幕 × 5 頁，每幕最後一頁是頭目（巨型墨瓶、剪刀魔、墨跡之書）。同樣計分，主選單右上角會顯示最高分。
- **無盡模式**：頁數無限、越來越難，每 5 頁出現一次頭目，以分數計算並記錄最高分。
- **循序漸進**：第一頁只有塗鴉兵，之後大約每 2～3 頁加入一種新敵人（墨團 → 散彈兵 → 墨雲 → 摺紙鳥 → 圓規手 → 橡皮怪），出現時標題會提示「新敵人」；無盡模式每 3 頁加入一種。
- 切換瀏覽器分頁或視窗失去焦點時會自動暫停。
- 暫停選單：繼續、查看牌組、圖鑑、設定、結算並回到主選單（先顯示本局結算再回到主選單）。暫停或查看牌組時鏡頭不會跟著滑鼠移動。
- **等級**：每局結束依表現獲得經驗，升級會解鎖新卡牌。卡牌一解鎖就會進入獎勵卡池，從第一幕第一頁起就有機會抽到（沒有依幕數限制）。圖鑑中的「等級 N 解鎖」就是該卡需要達到的等級。
- **上帝視角**：設定中開啟後，所有卡牌與敵人圖鑑立即解鎖、獎勵可抽到所有卡；開啟期間不會累積經驗與最高分，關閉後回到原本的等級與紀錄。
- **手牌**：2 張一般牌＋1 格特殊技；特殊技格已滿時，抽到的特殊技會直接進入棄牌堆。
- **卡牌合成**：牌組中有 3 張相同的一般牌時會播放升級動畫，合成為 1 張強化版；3 張相同的特殊技也會合成，效果不變但費用 -1。
- **頭目戰墨水**：頭目關卡中場上會不定時掉落少量墨水（每次 1 點，場上最多 2 個）。
- **場景**：墨水桶（射爆會範圍爆炸）、紙箱（打破可能掉落墨水或生命），部分房間有特殊規則（白霧：以玩家為中心之外的區域被擦淡；精英；急速）。
- 按 Esc 暫停時，滑鼠移到手牌上可以查看卡牌效果；點抽牌堆／棄牌堆可查看整副牌組，牌組中的卡同樣可以滑鼠移上去看效果。

### 選單與設定

- 開啟網頁時會先播放墨滴落下的加載動畫，分頁上有 INKRAGE 圖示。主選單左下角顯示目前版本號（例如 `beta v0.7.06`），每個版本的更新內容記錄在 [更新日誌.md](更新日誌.md)；所有卡牌、敵人、頭目與武器的數值整理在 [數值表.xlsx](數值表.xlsx)，可下載後填寫「修改建議」欄。
- 主選單：選單集中在畫面右側約 1/3 的紙面欄位（標題、關卡模式、無盡模式、訓練場、新手教學、圖鑑與等級框），左側 2/3 的中央是面向玩家的主角，鏡頭會緩慢環繞；「角色外觀」按鈕就在主角正下方，「設定」（齒輪圖示，滑鼠移上去會轉動）在左上角。選單與左側之間的手繪分隔線會緩緩擺動，並有墨滴沿線流下。
- **武器**：主選單「武器」可選擇每局使用的主武器（不列入圖鑑），每把都有示範動畫、數值條與說明，角色手上的武器外觀也會跟著換。升級會解鎖更多武器（上帝視角可全部解鎖）：

  每把武器有各自的射擊音效、槍口閃光與後座力，裝備或切換武器時角色會把武器轉一圈拿出來。「連射」等加速效果有射速上限，不會讓武器快到失控。連續命中時傷害數字不再合併成一個（以前看起來像兩倍傷害），遊戲沒有爆擊系統，紅色帶驚嘆號的數字只代表打中頭目弱點。

- **新手教學**：8 頁圖文說明（遊戲目標、移動與射擊、衝刺、墨水與卡牌、特殊技、敵人預警、牌組合成與獎勵、成長與練習），每頁左側有示範動畫；可用上一步／下一步、底部圓點、左右方向鍵切換，觸控裝置會顯示觸控版操作說明。沒看過之前按鈕旁會有紅色「推薦」標籤。點右上角的等級框可以打開「等級詳情」，列出每一級需要的累積經驗、會解鎖哪些卡牌，以及經驗的來源。
- **訓練場**：可以試用所有已解鎖的卡牌。一進場先選初始手牌（2 張一般牌＋1 張特殊技，或按「隨機」；選隨機時補牌方式自動改為隨機抽牌，手動選牌則為固定補牌）。訓練場設定與 Tab 選牌畫面開啟時遊戲會暫停，訓練資訊以遊戲時間計算。墨水與生命無限，畫面左上角改為「訓練資訊」框（總傷害、近 5 秒每秒傷害、最高單次、最後一擊、擊倒數、出牌數、被擊中次數、場上敵人）。
  - 按 Tab 或點抽牌堆可重新選卡；特殊技用掉後會自動補上（固定模式補回選的那張，隨機模式隨機補一張）。
  - 按 Esc（或右上角鈕）開啟「訓練場設定」：地圖（附地圖預覽框）、武器（下拉選單，可切換任一已解鎖武器）、障礙物、敵人會攻擊、敵人無限血量、無限彈藥（預設開）、補牌方式（固定補回選的牌／照常隨機抽牌）、頭目（巨型墨瓶／剪刀魔／墨跡之書可各自勾選召喚），以及敵人設定——每種敵人都有「一般」與「精英」兩組加減（總數上限 12），或開啟「隨機生成敵人」並設定數量與精英機率。未遇過的敵人無法選，塗鴉兵永遠可選。被打倒的敵人一律會重生。
- **角色外觀**：主選單的「角色外觀」可幫主角上色，有 8 套配色（「原稿」就是原本的黑白灰原皮，可隨時「恢復原皮」），套用配色後外框變細並改為深灰、陰影改為很淡的單向排線，讓塗色看得清楚（原稿配色保持原本的粗黑外框與交叉排線），也能分別選上衣與袖子、褲子與袖口、帽子與圍巾、手套／鞋／筆、臉與扣環、眼睛／鈕扣／筆尖的顏色。角色有帽簷、圍巾、腰帶、鈕扣、背包、手套與鞋子等細節；鏡頭拉近後角色面向玩家，按住滑鼠左鍵（或手指）左右拖曳可旋轉，設定自動儲存。
- **特殊技演出**：施放特殊技時遊戲會暫停，播放約 1.7 秒的全螢幕手繪演出，演出結束的瞬間（伴隨震撼的重擊音效與畫面震動）才真正發動技能。演出內容對應技能效果（例如紅墨處決先瞄準再劃叉擊碎敵人並跳出傷害數字、重畫擦掉敵彈後墨水流進墨水瓶、墨漩渦把敵人吸進去再爆炸、百筆齊發的筆會追蹤飛向敵人、定格把敵人與子彈凍結、回聲重播你上一張打出的卡、墨暴的閃電劈中敵人）；另外還有：卡牌像印章般甩上畫面、放射速度線、命中瞬間閃白並噴濺墨點，結束時名稱紙條撕成兩半退場；背景依技能不同（紅墨處決的紅色大叉、重畫的橡皮擦與重畫箭頭、墨水海嘯的墨浪、墨漩渦的漩渦、百筆齊發的筆雨、巨筆一劃的巨筆、定格的暫停框與裂痕、回聲的倒帶漣漪、墨暴的烏雲與紅色閃電），期間遊戲短暫慢動作；開啟「動態減少」時只顯示名稱。
- 圖鑑分為「一般牌／特殊技／敵人／頭目」四頁，可用滾輪或拖曳瀏覽。列表只顯示一句簡述與費用、傷害、方式等重點標籤，點開後才列出完整效果與數據。點卡牌會放大並循環播放施放示範；點敵人會列出生命、速度、擊殺墨水等數值（可切換成精英版本），並以動畫示範每一種攻擊方式與各自的傷害。一般牌可切換「基本／強化」預覽強化後的效果。每局一開始就在牌組裡的卡會標示「初始牌 ×張數」。還沒遇過的敵人只會顯示問號。
- 設定：音量、畫質（低／中／高）、輔助瞄準、動態減少（關閉畫面震動、頓幀、慢動作、線條抖動與強烈閃光）、全螢幕（預設開，第一次點擊或按鍵時自動進入瀏覽器全螢幕；Chrome／Edge 在全螢幕中按 Esc 會打開暫停選單、長按 Esc 才離開全螢幕，其他瀏覽器按 Esc 離開全螢幕時會自動暫停）、顯示 FPS、上帝視角，會自動儲存在瀏覽器。「重置等級」按鈕需連按三次（是否確認重置？→ 再按一次以重置 → 重置）才會把等級歸回 1，中途點其他地方即取消。「離開」與「結算」類按鈕滑鼠移上去時會變成淺紅色背景。「觸控設定」按鈕會打開獨立頁面，調整搖桿大小、水平位置、高度、瞄準內圈大小與技能鍵大小（畫面上即時預覽搖桿與技能鍵，每個滑桿右邊都有單獨恢復預設的按鈕，也可一鍵全部恢復預設）。下方的「按鍵說明」按鈕會列出鍵盤滑鼠與觸控的所有操作（遊戲畫面上不再常駐顯示）。每一項旁邊的 ⓘ 滑鼠移上去會說明這項在調整什麼。
- 畫質「低」會降低解析度、關閉紙紋與角色粗外框，適合效能較弱的裝置；平板預設為「中」。

### 整局流程

- 一局共 3 幕，每幕 5 頁（4 個戰鬥房間＋1 個頭目房間）。
- 只有每幕的第 1、3、5 頁有選卡獎勵：第 1、3 頁從 2 張卡中選 1 張（可跳過）；第 5 頁擊敗頭目後分成左右兩區，左邊一般牌 2 選 1、右邊特殊技 2 選 1（保證有特殊技），兩區可各選一張再按確定，每區右上角也有「這區不選」按鈕可單獨跳過該區。擊敗頭目回復 4 點生命。
- 選卡時每張卡下方會顯示牌組中已有幾張；再拿一張就會合成時會以紅字提示。
- 強化過的卡牌有雙層內框、下方角落塗黑與星號標記（特殊技為紅色）。
- 死亡即結束本局，顯示結算畫面後可重新開始。結算畫面像批改作業：標題以印章蓋上、分數從 0 滾動到最終值、紅筆圈出評等（S／A／B／C／D）、破紀錄時貼上「新紀錄」標籤，各項數據以便條卡片翻出，經驗條會動態填滿並在升級時變紅；通關時灑下彩色紙片，被擦除時畫面流下紅墨。
- 敵人腳下會用和彈匣相同的刻度弧線顯示血量，剛失去的血量會短暫以紅色標示（精英敵人為紅色刻度）。
- 選卡獎勵時滑鼠移到卡上會顯示效果。
- 輔助瞄準鎖定敵人時，敵人身上會出現旋轉的紅色鎖定框與頭頂箭頭，準心也會變紅；換彈時準心外圍會有一圈進度環（暫停時準心恢復原狀）。
- 傷害數字會彈出放大、大傷害與爆擊有放射線與紅色字。

### 敵人

| 敵人 | 行為 |
| --- | --- |
| 塗鴉兵 | 走位並射出單發紅色子彈 |
| 墨團 | 跳躍接近，死亡時分裂成兩隻小墨團 |
| 散彈兵 | 靠近到中距離，一次噴出 5 發扇形散彈（射程短） |
| 圓規手 | 保持距離，發射環狀彈幕 |
| 橡皮怪 | 衝撞玩家，會擦掉玩家畫的牆 |
| 墨雲 | 飄在空中保持距離，在玩家腳下與附近畫紅圈降下墨滴（爆開並留下減速墨漬）；擊倒後未落下的墨滴會消失 |
| 摺紙鳥 | 在空中盤旋，突然俯衝 |
| 巨型墨瓶（頭目） | 螺旋彈、扇形彈、環狀彈、丟出減速墨漬、召喚墨團；背後紅色裂縫受到三倍傷害 |
| 剪刀魔（頭目） | 衝刺剪擊、十字剪、旋轉彈幕；撞牆卡住時受到三倍傷害 |
| 墨跡之書（頭目） | 缺口彈幕牆、墨水雨、重擊、召喚小兵；攤開休息時受到三倍傷害 |

精英敵人與頭目頭上會有一圈紅色墨冠，精英敵人外框為暗紅色。

### 音效

- 所有音效皆為即時合成（Web Audio），以紙筆質感為主：射擊是筆尖輕點、命中是悶響、擊殺是紙張撕裂、特殊技是紙張刷過後的重擊加上鐘聲般的餘音，並加上輕微殘響與壓縮讓整體更一致。

### 墨水與卡牌

- 擊殺敵人會獲得墨水（上限 10），不同敵人給的量不同（以 0.5 為單位，例如塗鴉兵 1、墨團 1.5、橡皮怪 2、頭目 4，精英加倍），數值寫在圖鑑的敵人頁面；出牌需要消耗墨水（卡牌費用皆為整數）。墨水不足時點選或按快捷鍵選牌，卡牌會快速震動並閃紅提示，不會進入瞄準。
- 手牌 4 張，出牌 1 秒後補牌；抽牌堆用完會自動洗牌 2 秒，期間無法出牌。

網址加上 `?level=7` 可直接以指定等級遊玩（測試用）；`?mod=dark` 可強制房間特殊規則（dark／elite／hurry）。

網址加上 `?deck=all` 可以用全部 15 張卡作為牌組（測試用）；`?seed=數字` 可固定洗牌順序。

網址加上 `?quality=low`、`?quality=mid` 或 `?quality=high` 可以強制指定畫質。

## 本機執行

遊戲使用 ES modules，必須透過本機伺服器開啟，不能直接雙擊 `index.html`。

```
python -m http.server 8000
```

接著開啟 http://localhost:8000/

平板測試：電腦與平板連同一個 Wi-Fi，在平板瀏覽器開啟 `http://<電腦的區網 IP>:8000/`。
