# INKRAGE

3D 手繪風射擊 × 牌組構築遊戲。整個世界像是用鋼筆和鉛筆畫在筆記本紙上，以 Three.js 製作，不需要任何建置步驟。

## 線上遊玩

https://archie-30.github.io/INKRAGE/

（需先在 GitHub 開啟 Pages，推送到 `main` 後會自動部署。）

## 操作方式

### 桌機

| 按鍵 | 功能 |
| --- | --- |
| W A S D／方向鍵 | 移動 |
| 滑鼠 | 瞄準 |
| 滑鼠左鍵（按住） | 射擊（靠近敵人時會輔助鎖定） |
| R | 裝填（彈匣 12 發，打完會自動裝填） |
| Space／滑鼠右鍵 | 衝刺（衝刺期間與之後約 0.3 秒無敵） |
| 1／2／3 | 選取對應位置的卡牌（3 為特殊技格）；無目標卡直接出牌 |
| 左鍵點戰場 | 對選中的卡指定位置／方向施放（地面會顯示虛線預覽） |

| F2 | 切換畫質（低／中／高） |
| F3 | 顯示除錯資訊（FPS、繪製呼叫、三角形數） |

### 平板（觸控）

| 操作 | 功能 |
| --- | --- |
| 左下固定搖桿 | 移動（第一次觸碰螢幕後才會顯示） |
| 右下固定搖桿（雙圈） | 手指在內圈（虛線圈內）只轉向瞄準、不射擊；推到外圈（紅色細圈）才會射擊，內圈大小可調 |
| 右搖桿周圍的技能鍵 | 仿手遊技能鍵，繞著右搖桿排成一圈：衝刺、卡牌 1、卡牌 2、特殊技（顯示卡牌圖示與費用，墨水不足時變淡） |
| 點技能鍵 | 不需瞄準的牌（例如紙盾）直接施放；其他牌選取後用右搖桿或拖曳技能鍵瞄準，再點一次取消（觸控時中間的手牌只供查看，不能點選）。按住技能鍵時衝刺鍵會變成紅色叉叉，手指滑到叉叉上放開就取消施放 |
| 互動鍵 | 可以與角色、寶箱、音鈴互動或站在門裡時，衝刺鍵會變成「互動」鍵，並會微微晃動提醒可以按；戰鬥中太久（約 10 秒）沒用技能時，可以出的技能鍵會輪流晃一下提醒 |
| 按住技能鍵拖曳 | 直接瞄準，地上顯示虛線預覽，放開即施放 |
| 選牌後拖曳右搖桿 | 地上顯示虛線預覽，放開搖桿即施放（搖桿變紅色表示施放模式） |
| 選牌後點一下右搖桿 | 自動瞄準最近的敵人施放 |
| 鉛筆牆 | 選牌後用右搖桿擺放，或用手指在地上畫出路徑 |
| 暫停時點卡牌／牌組中點卡牌 | 顯示卡牌效果；牌組中點空白處先關閉說明，再點一次關閉牌組 |
| 選卡獎勵 | 點一下顯示效果，再點一次選擇 |
| 點抽牌堆 | 查看牌組 |
| 右上角「暫停」按鈕 | 暫停 |
| 三指同時觸碰 | 顯示除錯資訊 |

請橫向持握裝置。手機等小螢幕上整個介面會依畫面大小等比例縮小，描邊也會自動變細，避免角色糊成一片。在觸控與鍵盤滑鼠之間切換時，畫面上方會跳出「已切換至觸控操作／鍵盤滑鼠操作」的通知。第一次觸碰時會嘗試進入全螢幕；若瀏覽器不支援全螢幕（例如 iPhone 上的瀏覽器），會自動停用全螢幕設定並跳出提示，建議改用 Chrome。行動裝置若持續不順（低於約 42 FPS），遊戲會自動降低畫質。角色腳邊的地上有一個小三角形指向目前面向的方向；觸控時另有一條很淡的虛線畫出面向方向，方便瞄準（可在設定「觸控方向輔助」關閉）。

### 模式與成長

- **筆記本模式**：3 幕，每幕 6 頁加 1 頁頭目（巨型墨瓶、剪刀魔、墨跡之書）。每一頁都是一張實際走進去的地圖：
  - 過關後上方的門打開，門後的小空間裡有發光旋轉的紙頁並冒出光點；走進門裡按 F（觸控點提示框）確認，畫面四周出現黑色集中線指向門口，門口的白光越來越亮、擴散到整個畫面全白，接著下一頁從白紙上畫出來（轉場期間遊戲暫停）。站在門裡時提示框會附上那一區的簡短介紹。門上標示的頁面類型要過關後才會顯示。
  - 一般頁面上方會有 2～3 扇門，門上標示通往的頁面類型，可以先看好再選（還沒過關時，畫面外的門不會顯示方向提示）：一般戰、精英戰（第 2 幕起）、挑戰頁、寶箱頁、文具店、事件頁（小遊戲）、奇遇頁、修正液休息；每次至少有一扇是戰鬥。下一頁是頭目時只會有一扇門。
  - 進入每一頁時，畫面上方會出現目前這一幕的進度條（一條線、一頁一個點，最後的菱形是頭目頁），已經走過的點塗黑、目前所在頁是紅點並跳到新的一頁，幾秒後自動淡出；按暫停時暫停畫面上方也會顯示。右上角暫停鍵旁邊用大字顯示目前分數，加分或扣分時會震動、加分時放大變紅。
  - 非戰鬥頁（文具店、事件、奇遇、休息、寶箱）角色會收起武器、不能射擊；如果遇到伏擊，卡牌介面滑上來的同時角色會播放拿出武器的動畫。
  - 獲得、移除、升級或失去升級的卡牌，都會在畫面中央播放接近全螢幕的卡牌動畫（新卡從下方飛入再收進牌堆、被移除的卡會被撕成兩半掉落、升級時卡牌蓄力發光後變成強化版），可以點一下略過。事件、寶箱、商店等結果則只以文字顯示在右上角分數下方（沒有外框），加分會先跳出「+多少分」飛進分數再加上去。
  - **挑戰頁**：戰鬥加上條件（不受傷／限時／不使用卡牌），達成可加分並從稀有卡中挑一張，失敗則是一般獎勵。
  - **寶箱頁**：三個寶箱只能開一個，分別是稀有卡、補給，以及會咬人的假寶箱（伏擊戰）。
  - **文具店**：用分數購買服務，每次進去會從 9 種商品中隨機上架 3 種（不會跟上一間一樣）：挑一張卡（三選一，不能跳過）、稀有卡包（三張特殊技選一）、升級一張卡、隨機加工（隨機升級 2 張）、OK 繃（+2 生命）、大包紗布（+4 生命）、修正帶（挑一張卡移除）、補充墨水（+4 墨水）、武器交換（三把武器選一把換上），花掉的分數會從結算扣除。
  - **事件頁（小遊戲）**：每次都是一個小遊戲，不能跳過。場上先擺好遊戲的道具，和角落的主持人說話時，它會用一張筆記紙簡短說明玩法，按「開始！」就開始；畫面上方會顯示目前進度與剩餘秒數。過關會從獎勵池隨機抽一項（加分、選一張卡、稀有卡、回血、墨水、隨機升級卡……），失敗則從懲罰池隨機抽一項（扣血、扣分、被移除一張卡、卡片降級、下一場變精英戰、伏擊戰……），同一種獎懲不會連續抽到兩次；結果顯示在右上角分數下方。16 種小遊戲輪流出現（剛玩過的會先避開，數值隨幕數變難）：
    - 記憶音鈴：看音鈴亮起的順序，再走到音鈴旁按 F（觸控按互動鍵）照順序敲響；音鈴會擺動、發出鐘聲並震動畫面。
    - 塗鴉靶場：限時用武器打倒 6 個紙靶（主持人是戴帽子的教練，不是靶）。
    - 描線練習：沿著地上的虛線從起點走到終點，偏離太遠就失敗。
    - 推橡皮擦：用身體把大橡皮擦推進紅圈。
    - 倒墨水：站在踏板上墨水就會上升，在紅線附近離開踏板，溢出就失敗。
    - 踩格子：把每一格白色地板都踩黑，同一格不能踩兩次，也不能踩打叉的墨漬格；格子更多、時間更短（一定有解）。
    - 找不同：說明完開始後，兩張圖上的東西才會一個個蹦出來；在 B 圖上站到和 A 圖不一樣的格子裡停一下圈出來（找到的格子變紅並畫圈、錯的格子變黑打叉），可以錯一次。
    - 翻牌配對：站在牌上翻牌，一次兩張，配錯太多次就失敗（可容錯次數減少）。
    - 踩地雷：數字代表那一格周圍 8 格內的墨漬數，0 的格子會自動翻開附近的格子；墨漬數量減少。穿過格子走到對面的旗子，翻開的格子會顯示周圍幾格有墨漬，踩到墨漬就失敗。
    - 骰子賭運：站上「大」或「小」下注，猜中骰子點數的大小。
    - 紙飛機：站在發射台上瞄準垃圾桶，看準力道條按 F（觸控按互動鍵）丟出，三次機會。
    - 書本迷宮：更大的 8×5 迷宮、時間更短，書牆從起點向外依序升起，結束時依序沉下去，限時走到紅色星星。
    - 節奏踩點：音符從天上掉進三個圈圈，落地時站在那個圈裡接住它。
    - 跟著影子走：記住影子走過叉叉的順序，再照順序踩一遍。
    - 滾彈珠：用身體把彈珠撞進紅圈，避開黑洞。
    - 猜杯子：杯子數量隨機 3～5 個（後面的幕更容易抽到多杯）；記住墨珠在哪個杯子底下，杯子打亂後站到你猜的杯子前面。
  - **奇遇頁**：8 種奇怪遭遇輪流出現（打翻的墨水瓶、會說話的橡皮擦、塗鴉牆、同學的筆記、扭蛋機、削鉛筆機、打翻的咖啡、塗鴉幽靈），每個選項都有代價（例如失去生命、扣分、被隨機移除一張卡），有的會觸發伏擊戰；選完後畫面中間偏上會列出得到與失去的東西（扭蛋會顯示扭到什麼）。
  - **修正液休息**（出現機率較低）：回復生命（生命 4 以下固定 +2，否則隨機 +1～2），或選一張卡升級。
  - 非戰鬥頁不會顯示卡牌介面（按 Tab 可看到全部卡牌都在抽牌堆）；如果遇到伏擊，卡牌介面會滑上來，之後就一直保留。
  - 非戰鬥頁有好幾張地圖輪流出現，而且每次進去格局都會變：角色（或三個寶箱的排法）會出現在不同位置，周圍的擺設也會隨機換位、旋轉，整張圖還可能左右翻轉。靠近角色或寶箱後按 F（觸控點提示框或互動鍵）互動，選項會出現在一張貼著膠帶的筆記紙上（標題、說明與便條紙選項都用大字）；至少要互動過一次，上方的門才會打開。
  - 第 3 幕頭目倒下後上方會開兩扇門：「收筆結算」或「繼續寫下去」進入延長寫作（強度接續無盡模式、每 5 頁一隻頭目），分數持續累積。主選單右上角會顯示最高分。
- **無盡模式**：頁數無限、越來越難，每 5 頁出現一次頭目，以分數計算並記錄最高分。清除後走進上方發光的門並按 F 前往下一頁。
- **循序漸進**：第一頁只有塗鴉兵，之後大約每 2～3 頁加入一種新敵人（墨團 → 散彈兵 → 墨雲 → 摺紙鳥 → 圓規手 → 橡皮怪），出現時標題會提示「新敵人」；無盡模式每 3 頁加入一種。
- 切換瀏覽器分頁或視窗失去焦點時會自動暫停。
- 暫停選單：繼續、查看牌組、圖鑑、設定、結算並回到主選單（先顯示本局結算再回到主選單）。暫停或查看牌組時鏡頭不會跟著滑鼠移動。
- **等級**：共 10 級，每局結束依表現獲得經驗，升級會解鎖新卡牌與武器（升級所需經驗比以前多，大約要玩十幾到二十多局才會滿級）。結算後回到主畫面時，如果這段期間有升級，會播放「等級提升！」印章動畫，新解鎖的卡牌會一張張翻面飛出來，點一下繼續。主選單等級框打開的「等級詳情」會直接停在目前等級那一列。卡牌一解鎖就會進入獎勵卡池，從第一幕第一頁起就有機會抽到（沒有依幕數限制）。圖鑑中的「等級 N 解鎖」就是該卡需要達到的等級。
- **上帝視角**：設定中開啟後，所有卡牌與敵人圖鑑立即解鎖、獎勵可抽到所有卡；開啟期間不會累積經驗與最高分，關閉後回到原本的等級與紀錄。
- **手牌**：2 張一般牌＋1 格特殊技；特殊技格已滿時，抽到的特殊技會直接進入棄牌堆。
- **卡牌合成**：牌組中有 3 張相同的一般牌時會播放升級動畫，合成為 1 張強化版；3 張相同的特殊技也會合成，效果不變但費用 -1。
- **頭目戰墨水**：頭目關卡中場上會不定時掉落少量墨水（每次 1 點，場上最多 2 個）。
- **場景**：墨水桶（射爆會範圍爆炸）、紙箱（打破可能掉落墨水或生命），部分房間有特殊規則（白霧：以玩家為中心之外的區域被擦淡；精英；急速）。
- 按 Esc 暫停時，滑鼠移到手牌上可以查看卡牌效果；點抽牌堆／棄牌堆可查看整副牌組，牌組中的卡同樣可以滑鼠移上去看效果。

### 選單與設定

- 開啟網頁時會先播放墨滴落下的加載動畫，分頁上有 INKRAGE 圖示。主選單左下角顯示目前版本號（例如 `beta v0.9.10`），每個版本的更新內容記錄在 [更新日誌.md](更新日誌.md)；所有卡牌、敵人、頭目、武器與小遊戲（含獎懲機率）的數值整理在 [數值表.xlsx](數值表.xlsx)，可下載後填寫「修改建議」欄。
- 主選單：選單集中在畫面右側約 1/3 的紙面欄位（標題、筆記本模式、無盡模式、訓練場、新手教學、圖鑑與等級框），左側 2/3 的中央是面向玩家的主角，鏡頭會緩慢環繞；「角色外觀」按鈕就在主角正下方，「設定」（齒輪圖示，滑鼠移上去會轉動）在左上角。選單與左側之間的手繪分隔線會緩緩擺動，並有墨滴沿線流下。
- **武器**：主選單「武器」可選擇每局使用的主武器（不列入圖鑑），每把都有示範動畫、數值條與說明（實際數值直接寫在數值條左邊），角色手上的武器外觀也會跟著換。最下面的「隨機」在解鎖 2 把以上武器後開放：每局開始時從已解鎖的武器隨機挑一把，而且不會和上一局用的武器相同。升級會解鎖更多武器（上帝視角可全部解鎖）：

  | 圓規 | 9 | 20 | 冷卻 1.8 秒 | — | 丟出高速旋轉的圓規，直線飛出、到最遠處以同樣速度直線飛回手上（玩家移動時才會轉向），去回都穿透、可穿過紙箱與墨水桶，撞到牆壁（包含地圖四周的外牆）會彈回，不會飛出地圖；貼著牆邊沿牆丟出時不會再被牆誤判彈回；沒有彈匣與換彈，改為冷卻制：每丟一次要等角色腳下的冷卻條充滿才能再丟，這一丟沒打中任何敵人時剩下的冷卻會縮短為 4 成 |

  每把武器有各自的射擊音效、槍口閃光與後座力，裝備或切換武器時角色會把武器轉一圈拿出來。「連射」等加速效果有射速上限，不會讓武器快到失控。連續命中時傷害數字不再合併成一個（以前看起來像兩倍傷害），遊戲沒有爆擊系統，紅色帶驚嘆號的數字只代表打中頭目弱點。

- **新手教學**：8 頁圖文說明（遊戲目標、移動與射擊、衝刺、墨水與卡牌、特殊技、敵人預警、牌組合成與獎勵、成長與練習），每頁左側有示範動畫；可用上一步／下一步、底部圓點、左右方向鍵切換；文字精簡成重點，每頁同時寫出鍵鼠與觸控的操作。沒看過之前按鈕旁會有紅色「推薦」標籤。點右上角的等級框可以打開「等級詳情」，列出每一級需要的累積經驗、會解鎖哪些卡牌，以及經驗的來源。
- **訓練場**：可以試用所有已解鎖的卡牌。一進場先選初始手牌（2 張一般牌＋1 張特殊技，或按「隨機」；下方「回主畫面／隨機／放入手牌」三個按鈕排在一起，按錯可以直接回主畫面；選隨機時補牌方式自動改為隨機抽牌，手動選牌則為固定補牌）。訓練場設定與 Tab 選牌畫面開啟時遊戲會暫停，訓練資訊以遊戲時間計算。訓練場上方有兩扇門：左邊「回主畫面」（以進門動畫回到主選單），右邊「測試小遊戲」（打開 16 種小遊戲的選單，選了之後跑一般進頁的過場動畫進入那個小遊戲）。小遊戲玩完（不會有獎懲）上方會開兩扇門：左邊回訓練場、右邊再選另一個小遊戲。訓練場設定的地圖改為下拉選單（每個選項都有小地圖預覽，障礙物較清楚），並移除了「離開訓練場」按鈕。墨水與生命無限，畫面左上角改為「訓練資訊」框（總傷害、近 5 秒每秒傷害、最高單次、最後一擊、擊倒數、出牌數、被擊中次數、場上敵人）。
  - 按 Tab 或點抽牌堆可重新選卡；特殊技用掉後會自動補上（固定模式補回選的那張，隨機模式隨機補一張）。
  - 按 Esc（或右上角鈕）開啟「訓練場設定」：地圖（附地圖預覽框）、武器（下拉選單，可切換任一已解鎖武器）、障礙物、敵人會攻擊、敵人無限血量、無限彈藥（預設開）、補牌方式（固定補回選的牌／照常隨機抽牌）、頭目（巨型墨瓶／剪刀魔／墨跡之書可各自勾選召喚），以及敵人設定——每種敵人都有「一般」與「精英」兩組加減（總數上限 12），或開啟「隨機生成敵人」並設定數量與精英機率。未遇過的敵人無法選，塗鴉兵永遠可選。被打倒的敵人一律會重生。
- **角色外觀**：主選單的「角色外觀」可幫主角上色，有 8 套配色（「原稿」就是原本的黑白灰原皮，可隨時「恢復原皮」），套用配色後外框變細並改為深灰、陰影改為很淡的單向排線，讓塗色看得清楚（原稿配色保持原本的粗黑外框與交叉排線），也能分別選上衣與袖子、褲子與袖口、帽子與圍巾、手套／鞋／筆、臉與扣環、眼睛／鈕扣／筆尖的顏色。角色有帽簷、圍巾、腰帶、鈕扣、背包、手套與鞋子等細節；鏡頭拉近後角色面向玩家，按住滑鼠左鍵（或手指）左右拖曳可旋轉，設定自動儲存。左側面板放不下時可用滾輪或手指上下滑動。
- **特殊技演出**：施放特殊技時遊戲會暫停，播放約 1.7 秒的全螢幕手繪演出，演出結束的瞬間（伴隨震撼的重擊音效與畫面震動）才真正發動技能。演出內容對應技能效果（例如紅墨處決先瞄準再劃叉擊碎敵人並跳出傷害數字、重畫擦掉敵彈後墨水流進墨水瓶、墨漩渦把敵人吸進去再爆炸、百筆齊發的筆會追蹤飛向敵人、定格把敵人與子彈凍結、回聲重播你上一張打出的卡、墨暴的閃電劈中敵人）；另外還有：卡牌像印章般甩上畫面、放射速度線、命中瞬間閃白並噴濺墨點，結束時名稱紙條撕成兩半退場；背景依技能不同（紅墨處決的紅色大叉、重畫的橡皮擦與重畫箭頭、墨水海嘯的墨浪、墨漩渦的漩渦、百筆齊發的筆雨、巨筆一劃的巨筆、定格的暫停框與裂痕、回聲的倒帶漣漪、墨暴的烏雲與紅色閃電），期間遊戲短暫慢動作；開啟「動態減少」時只顯示名稱。
- 圖鑑分為「一般牌／特殊技／敵人／頭目」四頁，可用滾輪或拖曳瀏覽。列表只顯示一句簡述與費用、傷害、方式等重點標籤，點開後才列出完整效果與數據。點卡牌會放大並循環播放施放示範；點敵人會列出生命、速度、擊殺墨水等數值（可切換成精英版本），並以動畫示範每一種攻擊方式與各自的傷害。一般牌可切換「基本／強化」預覽強化後的效果。每局一開始就在牌組裡的卡會標示「初始牌 ×張數」。還沒遇過的敵人只會顯示問號。
- 設定：音量、畫質（低／中／高）、輔助瞄準、觸控方向輔助（預設開）、動態減少（關閉畫面震動、頓幀、慢動作、線條抖動與強烈閃光）、全螢幕（預設開，第一次點擊或按鍵時自動進入瀏覽器全螢幕；Chrome／Edge 在全螢幕中按 Esc 會打開暫停選單、長按 Esc 才離開全螢幕，其他瀏覽器按 Esc 離開全螢幕時會自動暫停）、顯示 FPS、上帝視角，會自動儲存在瀏覽器。「重置等級」按鈕只在主選單打開的設定裡出現，需連按三次（是否確認重置？→ 再按一次以重置 → 重置）才會把等級歸回 1（確認後播放翻頁動畫回到主畫面），中途點其他地方即取消。「離開」與「結算」類按鈕滑鼠移上去時會變成淺紅色背景。「觸控設定」按鈕會打開獨立頁面，調整搖桿大小、水平位置、高度、瞄準內圈大小與技能鍵大小（畫面上即時預覽搖桿與技能鍵，每個滑桿右邊都有單獨恢復預設的按鈕，也可一鍵全部恢復預設）。下方的「按鍵說明」按鈕會列出鍵盤滑鼠與觸控的所有操作（遊戲畫面上不再常駐顯示）。每一項旁邊的 ⓘ 滑鼠移上去會說明這項在調整什麼。
- 畫質「低」會降低解析度、關閉紙紋與角色粗外框，適合效能較弱的裝置；平板預設為「中」。

### 整局流程

- 一局共 3 幕，每幕 5 頁（4 個戰鬥房間＋1 個頭目房間）。
- 只有每幕的第 1、3、5 頁有選卡獎勵：第 1、3 頁從 2 張卡中選 1 張（可跳過）；第 5 頁擊敗頭目後分成左右兩區，左邊一般牌 2 選 1、右邊特殊技 2 選 1（保證有特殊技），兩區可各選一張再按確定，每區右上角也有「這區不選」按鈕可單獨跳過該區。擊敗頭目回復 4 點生命。
- 選卡時每張卡下方會顯示牌組中已有幾張；再拿一張就會合成時會以紅字提示。
- 強化過的卡牌有雙層內框、下方角落塗黑與星號標記（特殊技為紅色）。
- 有持續時間的卡牌效果（連射、雙持、疾筆、反彈紙、時停、墨水場等）會在角色腳下顯示一條倒數條與效果名稱，同時有多個效果時顯示最快結束的那個；分身的倒數條顯示在分身身上。
- 施放卡牌一律以按下施放當下的位置為起點，不會因為出牌動畫期間的移動而偏掉。
- 死亡即結束本局，顯示結算畫面後可重新開始。結算畫面像批改作業（破最高分時會蓋上「創新高分！」印章並放煙火、灑紙片；「本局明細」按鈕可以查看每一頁的類型、擊倒、傷害、出牌、用時與分數變化）：標題以印章蓋上、分數從 0 滾動到最終值、紅筆圈出評等（S／A／B／C／D，依本局總分決定；滑鼠移上去或觸控點一下可查看各評等的分數門檻）、破紀錄時貼上「新紀錄」標籤，各項數據以便條卡片翻出，經驗條會動態填滿並在升級時變紅；通關時灑下彩色紙片，被擦除時畫面流下紅墨。
- 敵人腳下會用和彈匣相同的刻度弧線顯示血量，剛失去的血量會短暫以紅色標示（精英敵人為紅色刻度）。
- 選卡獎勵時滑鼠移到卡上會顯示效果。
- 輔助瞄準鎖定敵人時，敵人身上會出現旋轉的紅色鎖定框與頭頂箭頭，準心也會變紅；換彈時準心外圍會有一圈進度環（暫停時準心恢復原狀）。
- 傷害數字會彈出放大、大傷害與爆擊有放射線與紅色字。

### 音效

- 所有音效皆為即時合成（Web Audio），以紙筆質感為主：射擊是筆尖輕點、命中是悶響、擊殺是紙張撕裂、特殊技是紙張刷過後的重擊加上鐘聲般的餘音，並加上輕微殘響與壓縮讓整體更一致。

### 墨水與卡牌

- 擊殺敵人會獲得墨水（上限 10），不同敵人給的量不同（以 0.5 為單位，例如塗鴉兵 1、墨團 1.5、橡皮怪 2、頭目 4，精英加倍），數值寫在圖鑑的敵人頁面；出牌需要消耗墨水（卡牌費用皆為整數）。墨水不足時點選或按快捷鍵選牌，卡牌會快速震動並閃紅提示，不會進入瞄準。
- 手牌 4 張，出牌 1 秒後補牌；抽牌堆用完會自動洗牌 2 秒，期間無法出牌。

網址加上 `?level=7` 可直接以指定等級遊玩（測試用）；`?mod=dark` 可強制房間特殊規則（dark／elite／hurry）。

網址加上 `?deck=all` 可以用全部 15 張卡作為牌組（測試用）；`?seed=數字` 可固定洗牌順序。

網址加上 `?quality=low`、`?quality=mid` 或 `?quality=high` 可以強制指定畫質。

## 本機執行

遊戲使用 ES modules，必須透過本機伺服器開啟，不能直接雙擊 `index.html`。

```
python -m http.server 8000
```

接著開啟 http://localhost:8000/

平板測試：電腦與平板連同一個 Wi-Fi，在平板瀏覽器開啟 `http://<電腦的區網 IP>:8000/`。
