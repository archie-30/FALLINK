# INKRAGE

3D 手繪風射擊 × 牌組構築遊戲。整個世界像是用鋼筆和鉛筆畫在筆記本紙上，以 Three.js 製作，不需要任何建置步驟。

## 線上遊玩

https://archie-30.github.io/INKRAGE/

（需先在 GitHub 開啟 Pages，推送到 `main` 後會自動部署。）

## 操作方式

### 桌機

| 按鍵 | 功能 |
| --- | --- |
| W A S D／方向鍵 | 移動 |
| 滑鼠 | 瞄準 |
| 滑鼠左鍵（按住） | 射擊（靠近敵人時會輔助鎖定） |
| R | 裝填（彈匣 12 發，打完會自動裝填） |
| Space／滑鼠右鍵 | 衝刺（衝刺期間與之後約 0.3 秒無敵） |
| 1／2／3 | 選取對應位置的卡牌（3 為特殊技格）；無目標卡直接出牌 |
| 左鍵點戰場 | 對選中的卡指定位置／方向施放（地面會顯示虛線預覽） |
| 再按同一個數字鍵 | 立即朝滑鼠位置施放 |
| 鉛筆牆 | 選牌後按住左鍵在地上畫出牆的路徑，放開即長出牆 |
| Esc／右鍵 | 取消瞄準 |
| Tab | 查看牌組（抽牌堆／棄牌堆，遊戲暫停） |
| F | 與地圖裡的角色或寶箱互動；站在門裡時確認進入下一頁 |

> 用電腦遊玩時，卡牌與牌堆只能用快捷鍵操作（滑鼠點卡牌不會出牌）；出牌後新抽的牌會補回原本的位置。
| F2 | 切換畫質（低／中／高） |
| F3 | 開發者模式中隱藏／顯示除錯資訊（FPS、繪製呼叫、三角形數）；除錯面板只有開啟開發者模式時才會出現 |
| Esc／P | 暫停（Esc 在瞄準卡牌時為取消瞄準） |

### 平板（觸控）

| 操作 | 功能 |
| --- | --- |
| 左下固定搖桿 | 移動（第一次觸碰螢幕後才會顯示） |
| 右下固定搖桿（雙圈） | 手指在內圈（虛線圈內）只轉向瞄準、不射擊；推到外圈（紅色細圈）才會射擊，內圈大小可調 |
| 右搖桿周圍的技能鍵 | 仿手遊技能鍵，繞著右搖桿排成一圈：衝刺、卡牌 1、卡牌 2、特殊技（顯示卡牌圖示與費用，墨水不足時變淡） |
| 點技能鍵 | 不需瞄準的牌（例如紙盾）直接施放；其他牌選取後用右搖桿或拖曳技能鍵瞄準，再點一次取消（觸控時中間的手牌只供查看，不能點選）。按住技能鍵時衝刺鍵會變成紅色叉叉，手指滑到叉叉上放開就取消施放 |
| 互動鍵 | 可以與角色、寶箱、音鈴互動或站在門裡時，衝刺鍵會變成「互動」鍵，並會微微晃動提醒可以按；戰鬥中太久（約 10 秒）沒用技能時，可以出的技能鍵會輪流晃一下，旁邊還會擴散出像音波一樣的圓環提醒（訓練場不會） |
| 按住技能鍵拖曳 | 直接瞄準，地上顯示虛線預覽，放開即施放 |
| 選牌後拖曳右搖桿 | 地上顯示虛線預覽，放開搖桿即施放（搖桿變紅色表示施放模式） |
| 選牌後點一下右搖桿 | 自動瞄準最近的敵人施放 |
| 鉛筆牆 | 選牌後用右搖桿擺放，或用手指在地上畫出路徑 |
| 暫停時點卡牌／牌組中點卡牌 | 顯示卡牌效果；牌組中點空白處收起說明，牌多時可上下滑動，按「關閉」才會離開牌組 |
| 選卡獎勵 | 點一下顯示效果，再點一次選擇 |
| 點抽牌堆 | 查看牌組 |
| 右上角「暫停」按鈕 | 暫停 |
| 三指同時觸碰 | 開發者模式中隱藏／顯示除錯資訊（一般玩家不會誤觸） |

請橫向持握裝置。手機上鏡頭會比電腦更靠近角色、角度稍低。手機等小螢幕上整個介面會依畫面大小等比例縮小，描邊也會自動變細，避免角色糊成一片。在觸控與鍵盤滑鼠之間切換時，畫面上方會跳出「已切換至觸控操作／鍵盤滑鼠操作」的通知（剛進入遊戲第一次觸控時不會跳出）；所有介面上的操作說明也會跟著目前使用的裝置切換（觸控時只顯示點一下、拖曳、互動鍵等說法，鍵鼠時才顯示按鍵與滑鼠說明）。第一次觸碰時會嘗試進入全螢幕；若瀏覽器不支援全螢幕（例如 iPhone 上的瀏覽器），會自動停用全螢幕設定並跳出提示，建議改用 Chrome。效能：遊戲第一次啟動時會量測螢幕更新率與裝置等級，旗艦手機（120Hz 螢幕、8 核心以上）預設高畫質 120 FPS，一般手機預設中畫質 90 FPS（60Hz 螢幕則 60），較弱的裝置預設低畫質；之後可在設定自行調整。遊戲中會即時監測幀率，跟不上目標時先自動降低 3D 畫面的渲染解析度（介面文字與按鈕維持清晰，順暢時再慢慢調回），降到下限（低／中／高畫質分別約 70%／80%／88%）後還要持續不順約 14 秒才會自動降一級畫質（只有「從沒手動選過畫質」時才會自動降級；只要你在設定或按 F2 自己選過畫質，就不會再被自動降級）；這個自動降級只在本次遊玩有效，不會寫進存檔，下次開啟會回到你原本選的畫質（自己在設定或按 F2 改的畫質才會被記住）。開啟開發者模式時右上角會顯示 FPS／目標、動態解析度、繪製呼叫與實際渲染解析度，方便在手機上實測。角色腳邊的地上有一個小三角形指向目前面向的方向；觸控時另有一條很淡的虛線畫出面向方向，方便瞄準（可在設定「觸控方向輔助」關閉）。

### 模式與成長

- **筆記本模式**：3 幕，每幕 6 頁加 1 頁頭目。頭目每次都從六隻中隨機抽出一隻（同一局不重複）：巨型墨瓶、剪刀魔、墨跡之書、考卷魔王、巨筆暴君、大鬧鐘。所有頭目血量降到門檻（巨筆暴君三分之一、其他一半）時會鎖血、播放進化動畫（邊旋轉邊變大、身體轉紅、頭上冒出台詞，期間刀槍不入），接著進入第二型態並加入新的招式；頭目血條上的紅色刻度就是進化門檻。越後面的幕，頭目攻擊越頻繁、血量越多，第 2 幕起還會定時召喚小兵（第 2 幕塗鴉兵，第 3 幕再加摺紙鳥與散彈兵）。每一頁都是一張實際走進去的地圖：
  - 過關後上方的門打開，門後的小空間裡有發光旋轉的紙頁並冒出光點；走進門裡按 F（觸控點提示框）確認，畫面四周出現黑色集中線指向門口，門口的白光越來越亮、擴散到整個畫面全白，接著下一頁從白紙上畫出來（轉場期間遊戲暫停）。站在門裡時提示框會附上那一區的簡短介紹。門上標示的頁面類型要過關後才會顯示。
  - 一般頁面上方會有 2～3 扇門，門上標示通往的頁面類型，可以先看好再選（還沒過關時，畫面外的門不會顯示方向提示）：一般戰、精英戰（第 2 幕起）、挑戰頁、寶箱頁、文具店、事件頁（小遊戲）、奇遇頁、休息區；每次至少有一扇是戰鬥。下一頁是頭目時只會有一扇門。頭目倒下後不會直接跳出獎勵，上方只開一扇「圖書館」門。
  - 進入每一頁時，畫面上方會出現目前這一幕的進度條（一條線、一頁一個點，最後的菱形是頭目頁），已經走過的點塗黑、目前所在頁是紅點並跳到新的一頁，幾秒後自動淡出；按暫停時暫停畫面上方也會顯示。右上角暫停鍵旁邊用大字顯示目前分數，加分或扣分時會震動、加分時放大變紅。
  - 非戰鬥頁（文具店、事件、奇遇、休息區、寶箱、圖書館）角色會收起武器、不能射擊；如果遇到伏擊，卡牌介面滑上來的同時角色會播放拿出武器的動畫。
  - 獲得、移除、升級或失去升級的卡牌，都會在畫面中央播放接近全螢幕的卡牌動畫（新卡從下方飛入再收進牌堆、被移除的卡會被撕成兩半掉落、升級時卡牌蓄力發光後變成強化版；一次升級兩張卡時兩張會左右並排一起播放，不用看兩次；升級時畫面中間不再另外跳出「已升級」的小框），可以點一下略過。自選升級哪一張卡時，升級後效果的說明放在卡牌下方獨立的紙條裡（最多兩行），不會被卡牌或按鈕擋住。事件、寶箱、商店等結果則只以文字顯示在右上角分數下方（沒有外框），加分會先跳出「+多少分」飛進分數再加上去。
  - **挑戰頁**：戰鬥加上條件（不受傷／限時／不使用卡牌），達成可加分並從稀有卡中挑一張，失敗則是一般獎勵。
  - **寶箱頁**：三個寶箱只能開一個，分別是稀有卡、補給，以及會咬人的假寶箱（伏擊戰）。
  - **文具店**：商品直接陳列在老闆前方的展示台上（每樣商品上方有名稱與價格牌，分數不夠時價格變紅；老闆正前方不會生成擺設擋住；靠近商品時的介紹彈窗會蓋在其他價格牌上方），走到商品旁按 F 就能用分數購買；觸控操作時要按兩次才會買（第一次按互動鍵或提示框，互動鍵會變成紅色的「確認」、提示框變紅並寫著「再按一次互動，確認購買「商品名」」，3 秒內再按一次才會付款，走開或超過 3 秒就取消），老闆會在頭上的對話框說話（歡迎光臨、分數不夠、謝謝惠顧等）；和老闆說話或買過一樣東西後上方的門就會打開。每次進去會從 9 種商品中隨機上架 3 種（不會跟上一間一樣）：挑一張卡（三選一，不能跳過）、稀有卡包（三張特殊技選一）、升級一張卡、隨機加工（隨機升級 2 張）、OK 繃（+2 生命）、大包紗布（+4 生命）、修正帶（挑一張卡移除；選卡畫面左下有「反悔（退回一半分數）」按鈕，不想撕卡時按下去會退回一半的價錢，這件商品仍算已買）、補充墨水（+4 墨水）、武器交換（三把武器選一把換上），花掉的分數會從結算扣除。
  - **事件頁（小遊戲）**：每次都是一個小遊戲，不能跳過。場上先擺好遊戲的道具，和角落的主持人說話時，它會用一張筆記紙簡短說明玩法，按「開始！」就開始；畫面上方會顯示目前進度與剩餘秒數。過關會從獎勵池隨機抽一項（加分、選一張卡、稀有卡、回血、墨水、隨機升級卡……），失敗則從懲罰池隨機抽一項（扣血、扣分、被移除一張卡、卡片降級、下一場變精英戰、伏擊戰……），同一種獎懲不會連續抽到兩次；結果顯示在右上角分數下方，主持人也會在頭上的對話框說一句話（過關時誇獎，失敗時說「好可惜……」之類的話；主持人在畫面外時對話框會貼在畫面邊緣）。18 種小遊戲輪流出現（剛玩過的會先避開，數值隨幕數變難）：
    - 記憶音鈴：每次隨機敲 4～6 下，看音鈴亮起的順序，再走到音鈴旁按 F（觸控按互動鍵）照順序敲響；音鈴會擺動、發出鐘聲並震動畫面。
    - 塗鴉靶場：限時用武器打倒 6 個紙靶（主持人是戴帽子的教練，不是靶）。
    - 描線練習：沿著地上的虛線從起點走到終點，偏離太遠就失敗。
    - 推橡皮擦：用身體把大橡皮擦推進紅圈。
    - 倒墨水：站在踏板上墨水就會上升，在紅線附近離開踏板，溢出就失敗。
    - 踩格子：把每一格白色地板都踩黑，同一格不能踩兩次，也不能踩打叉的墨漬格；格子更多、時間更短（一定有解）。
    - 找不同：說明完開始後，兩張圖上的東西才會一個個蹦出來；在 B 圖上站到和 A 圖不一樣的格子裡停一下圈出來（找到的格子變紅並畫圈、錯的格子變黑打叉），可以錯一次。
    - 翻牌配對：站在牌上翻牌，一次兩張，配錯太多次就失敗（可容錯次數減少）。
    - 躲墨雨：一朵墨雲飄在場地上空，地上會先出現越來越大的影子，墨滴落下時站在影子裡就會被淋到；被淋到太多次就失敗，撐到時間結束就成功（越後面掉得越頻繁、影子越快落下、一次掉兩滴的機率也越高，部分墨滴會瞄準你的位置；時間一到場上的影子與墨滴會全部清空）。
    - 骰子賭運：站上「大」或「小」下注，猜中骰子點數的大小。
    - 紙飛機：站在發射台上瞄準垃圾桶，看準力道條按 F（觸控按互動鍵）丟出；要投進左右兩個垃圾桶，最多可失誤 4 次，站在發射台時鏡頭會自動拉開，讓主角和桶子都在畫面內。
    - 書本迷宮：更大的 8×5 迷宮、時間更短，開始前地板上不會顯示路線，書牆從起點向外依序升起，結束時依序沉下去，限時走到紅色星星。
    - 節奏踩點：音符從天上掉進三個圈圈，落地時站在那個圈裡接住它。
    - 跟著影子走：記住影子走過叉叉的順序，再照順序踩一遍；影子走過的地方會留下一條逐漸淡去的紅色墨跡。
    - 滾彈珠：用身體把彈珠撞進紅圈，避開黑洞。
    - 猜杯子：杯子數量隨機 3～5 個（後面的幕更容易抽到多杯）；記住墨珠在哪個杯子底下，杯子打亂後站到你猜的杯子前面。
    - 老師說：站在中間的圈圈等老師下指令（畫面上方大字＋老師頭上的對話框），只有「老師說：」開頭的才要照做——向左／向右跑進那邊的圈圈、衝刺就按衝刺；沒說「老師說」就站著別動（離開中間太遠或衝刺都算錯）。假指令大約占一半，而且多半會用「老師想／老師猜／老師講／老師覺得」這類開頭混淆，第 2 幕起還會出現「老是說／老師說說／老帥說／老司說」這種看起來很像的。每個指令判定時畫面上方會閃大字（黑色「○ 答對了！」或紅色「✕ 答錯了！」），腳下蓋一個大大的黑圈或紅叉，答錯時畫面會震一下。每個指令做完要先回到中間站穩才會出下一個；第一個指令一定是真的，假指令最多連續兩個。第 2 幕起會有「先左後右／先右後左」，第 3 幕還有老師頭上反方向的箭頭干擾。每幕指令 8／10／12 個、可錯 3／3／2 次，錯太多就失敗（另有總時間保險）。
    - 心中有數：和主持人說完話後，畫面上方會告訴你這次要數幾秒（6～11 秒隨機整數），角色被傳送到場中間的大碼錶前面；碼錶倒數 3、2、1 後開始跑，跑到 3～4 秒時螢幕會慢慢暗掉，接下來只能在心裡默數，覺得時間到了就按互動鍵（手機點互動鈕，不需二次確認）停下碼錶，螢幕重新亮起顯示停下的秒數（到小數點後兩位）。誤差 ±0.3 秒內算「完美」（多拿一項獎勵）、±0.6 秒內算過關，其他都算失敗；碼錶是實體，走不過去；超過目標 5 秒還沒按也算失敗。
  - **奇遇頁**：8 種奇怪遭遇輪流出現（打翻的墨水瓶、會說話的橡皮擦、塗鴉牆、同學的筆記、扭蛋機、削鉛筆機、打翻的咖啡、塗鴉幽靈），每個選項都有代價（例如失去生命、扣分、被隨機移除一張卡），有的會觸發伏擊戰；選完後畫面中間偏上會列出得到與失去的東西（扭蛋會顯示扭到什麼；扭蛋機選項的每個機率各自一行）。
  - **休息區**（出現機率較低，權重 0.3）：回復生命（生命 4 以下固定 +2，否則隨機 +1～2），或選一張卡升級。
  - 非戰鬥頁不會顯示卡牌介面（按 Tab 可看到全部卡牌都在抽牌堆）；如果遇到伏擊，卡牌介面會滑上來，之後就一直保留。
  - 非戰鬥頁有好幾張地圖輪流出現，而且每次進去格局都會變：角色（或三個寶箱的排法）會出現在不同位置，周圍的擺設也會隨機換位、旋轉，整張圖還可能左右翻轉；堆疊的書本與紙團都有碰撞，角色不會再走進去。靠近角色或寶箱後按 F（觸控點提示框或互動鍵）互動，選項會出現在一張貼著膠帶的筆記紙上（標題、說明與便條紙選項都用大字）；至少要互動過一次，上方的門才會打開。
  - **圖書館**（每次擊敗頭目後）：四周是高大的書架、攤開的巨書與燭台，連玩家走不到的場景外圍也有書架、拱門與書堆。左邊兩位守卡人：「守卡人」可從 2 張一般牌選 1、「特殊技守卡人」可從 2 張特殊技選 1（都可跳過）。右邊的「圖書管理員」站在紅色符文圈與燭火之間，身旁漂浮 3 件遺物（從已解鎖、還沒帶在身上的遺物中隨機抽），走近可像商店一樣看到效果說明，按互動免費拿走其中 1 件（手機上要按兩次確認），拿了之後另外兩件只能看不能選。兩位守卡人都互動過、遺物也拿了，上方的門才會打開（第 1、2 幕與課表模式只有一扇「前往下一幕」，因為每一幕的第一頁都是一般戰；第 3 幕則是「收筆結算／繼續寫下去」兩扇），所以遺物一定要拿。身上最多 4 件遺物，拿到第 5 件時會跳出視窗選一件丟掉。
  - 第 3 幕頭目倒下後（經過圖書館）上方會開兩扇門：「收筆結算」或「繼續寫下去」進入延長寫作（強度接續課表模式、每 5 頁一隻頭目），分數持續累積。最高分顯示在主選單「筆記本模式」按鈕下方。
- **課表模式**（原「無盡模式」）：頁數無限、越來越難（每頁敵人數量比以前多一些，一開始就有 4 種敵人輪流登場，之後每 3 頁加入一種新敵人），每 5 頁為一幕：前 4 頁各抽一堂不同的課（同一幕不會重複抽到同一堂，跨幕可重複），第 5 頁打隨機頭目（頭目頁沒有課程效果）；每一幕的第 1、3、5 頁有選卡獎勵，以分數計算並記錄最高分。清除後走進上方發光的門並按 F 前往下一頁。
  - **課程**：每堂課有各自的特殊效果與一個挑戰，完成挑戰會立刻拿到獎勵。進入新的課程會彈出說明視窗（字級較大，先是一句話介紹，下面用精簡列點列出「特殊效果」「挑戰」「挑戰完成獎勵」，內容多時可上下拖曳；視窗上下與螢幕邊緣留有空隙）；同一局再遇到同一堂課就不再彈出。畫面上方中間有一條沒有刻度的挑戰進度條（手繪風格，像筆記本模式的節點進度，右邊是進度或剩餘時間）；課表模式遊玩時畫面最上方顯示目前這堂課的名稱（頭目頁顯示頭目名稱），不再顯示第幾幕第幾頁，右上角分數旁的圓形圖示是目前的課，點一下會暫停遊戲並重新顯示課程說明（關閉後依設定倒數 3 秒）。
  - 目前有 5 堂課：**數學課**（每次隨機挑 2 隻敵人頭上標同一個數字，從 1 開始；打倒其中一隻後，另一隻的數字會拿掉，再隨機挑 2 隻標下一個數字，一路到 5；沒標數字的敵人傷害 −60%；場上敵人不夠時會補上新的敵人，打倒標 5 的敵人才算完成，之後清掉剩下的敵人才會開門；挑戰：從 1 打到 5；獎勵：墨水補滿）、**體育課**（你的移速 +20%、敵人與敵彈速度也 +20%；挑戰：90 秒內清場；獎勵：1 金幣）、**資訊課**（每 6 秒有一隻敵人複製自己，副本只有一半血，本尊倒下副本消失；挑戰：擊倒所有本尊；獎勵：回復 2 點生命）、**訓導課**（老師每 1.6 秒從你附近（畫面內）丟一支粉筆：先在出手處地上出現紅圈預警約 0.7 秒，再朝你的位置射出灰白色的粉筆（打到扣 1 血，會穿過障礙物），衝刺冷卻 −40%；挑戰：衝刺閃過子彈 4 次；獎勵：1 金幣）、**音樂課**（戰鬥時地板上每 2.6 秒左右貼出一個圈圈（有透視、貼著地面，圈內有淡紅底色），出現在你附近（約 2～6 步內）且會避開敵人至少 3 步，避免被敵人圍住；3 秒後消失，外圈會往內縮、快消失時圈會閃紅；挑戰：踩進 5 個圈圈；獎勵：回復 1 點生命並補滿墨水）。課程說明視窗只有一句話介紹加精簡列點。每項數值整理在 [數值表.xlsx](數值表.xlsx) 的「課程」分頁。
- **循序漸進**：第一頁只有塗鴉兵，之後大約每 2 頁加入一種新敵人（墨團 → 散彈兵 → 橡皮印章兵 → 墨雲 → 摺紙鳥 → 圓規手 → 橡皮怪），出現時標題會提示「新敵人」；課表模式每 2 頁加入一種。課表模式第一頁起就有塗鴉兵、墨團、散彈兵、橡皮印章兵 4 種輪流出現（每頁挑 3 種，優先換上和上一頁不同的），之後每 3 頁加入一種（墨雲 → 摺紙鳥 → 圓規手 → 橡皮怪）。為了畫面不要太亂，每一頁最多只出現 3 種一般敵人，並優先換上和上一頁不同的種類，讓各種敵人輪流登場。
- **攻擊節奏錯開**：每隻小怪出生時都有自己的攻擊節奏（在原本的攻擊間隔範圍內隨機選一個基準，再乘上 0.85～1.2 倍），之後每次攻擊都在自己的基準 ±12% 內隨機；第一次攻擊另外多 0～1.4 秒的隨機延遲。同時進場的敵人不會再幾乎同時開火。
- 切換瀏覽器分頁或視窗失去焦點時會自動暫停，同時放開所有按住的按鍵、搖桿與卡牌；暫停或設定介面顯示時（包含淡出動畫期間），點擊與放開都不會穿透到背後的卡牌或按鈕。
- 暫停選單：繼續、查看牌組、圖鑑、設定、結算並回到主選單（先顯示本局結算再回到主選單）。戰鬥中（或有計時的小遊戲中）按「繼續」後會先回到遊戲畫面並在中央倒數 3 秒（非戰鬥狀態與沒有計時的小遊戲則直接繼續，不倒數），倒數期間可以先調整搖桿方向，但角色不會移動也不能射擊或出牌，倒數結束立刻接續遊戲。暫停或查看牌組時鏡頭不會跟著滑鼠移動。
- **等級**：共 15 級（每級會新增 2～3 張卡牌；等級 5、10、15 在「等級詳情」該等級那一列的右邊有一個寶箱圖示，達到等級後寶箱會發光跳動，點一下就能打開（5 金幣＋1 個顏色＋1 個配飾），主選單等級框右上角會出現紅點提醒還有寶箱沒開；之前已經超過 5 或 10 級的玩家也能直接點開），每局結束依表現獲得經驗，升級會解鎖新卡牌與武器（升級所需經驗：第 1 級 340，之後每級多 210；比以前再多一些，大約要玩十幾到二十多局才會滿級）。結算後回到主畫面時，如果這段期間有升級，會播放「等級提升！」印章動畫，新解鎖的卡牌會一張張翻面飛出來，點一下繼續。主選單等級框打開的「等級詳情」會直接停在目前等級那一列。卡牌一解鎖就會進入獎勵卡池，從第一幕第一頁起就有機會抽到（沒有依幕數限制）。圖鑑中的「等級 N 解鎖」就是該卡需要達到的等級。等級詳情中還沒解鎖的卡牌是灰色的，其中特殊技（大招）會改用淡紅色顯示，一眼就能分辨。
- **開發者模式**：設定中點開後需輸入開發者密碼才能開啟（畫面上會跳出數字鍵盤，手機也能直接點）；開啟後，所有卡牌與敵人圖鑑立即解鎖、獎勵可抽到所有卡；開啟期間不會累積經驗與最高分，關閉後回到原本的等級與紀錄，如果當時選的武器在目前等級還沒解鎖，會自動換回鋼筆。
- **手牌**：2 張一般牌＋1 格特殊技；特殊技格已滿時，抽到的特殊技會直接進入棄牌堆。
- **卡牌合成**：牌組中有 3 張相同的一般牌時會播放升級動畫，合成為 1 張強化版；3 張相同的特殊技也會合成，效果不變但費用 -1。
- 吸墨紙選取後會在角色周圍畫出作用範圍的虛線圈：鍵鼠再按一次數字鍵或點左鍵施放；觸控按住技能鍵往任意方向滑出就立即施放。
- 雙持（特殊技，6 秒）期間螢光筆也會左右手各射出一道光束，兩道光束平行，瞄準點（含輔助瞄準）在兩道中間。墨漩渦爆炸時如果只炸到 1 個敵人，改為造成 100 傷害（強化版 140）。
- 頭目倒下時場上剩下的敵人會直接消失，不再跳出一大串傷害數字。
- **嘲諷**：頭目與精英敵人活著的時候，會不時在頭上冒出紅色對話框嘲諷你（例如「就這？」），共有 36 句隨機輪替，不容易重複。
- **頭目戰墨水**：頭目關卡中場上會不定時掉落少量墨水（只會掉在離玩家與所有敵人都有一段距離的空地，不會生成在怪物旁邊）（每次 1 點，場上最多 2 個）。
- **場景**：墨水桶（射爆會範圍爆炸；站在爆炸範圍中心附近會被炸掉 3 點生命）、紙箱（打破可能掉落墨水或生命），部分房間有特殊規則（白霧：以玩家為中心之外的區域被擦淡；精英；急速）。
- 按 Esc 暫停時，滑鼠移到手牌上可以查看卡牌效果；點抽牌堆／棄牌堆可查看整副牌組，牌組中的卡同樣可以滑鼠移上去看效果。

### 選單與設定

- **中途關閉遊戲**：筆記本或課表模式玩到一半就把遊戲從後台關掉的話，每次清完一頁（門打開時）與走進下一扇門前都會自動記錄一次進度；下次開啟遊戲回到主選單時會跳出「上次的遊戲還沒結束」視窗，顯示模式、最後完整通過的頁與目前分數，可選「繼續遊玩」（回到那一頁、門已打開，生命、墨水、牌組、武器、遺物與分數都和當時一樣）或「立即結算」（直接以那一頁的成績進入結算畫面，照常拿經驗與寶箱）；視窗內只列出模式、進度與分數，不另外解釋兩個按鈕。死亡或正常結算後就不會再跳出。
- **頭目初次遭遇**：第一次遇到某個頭目時，遊戲會暫停並跳出和圖鑑相同的頭目資料頁（生命、弱點與每招攻擊方式的動畫），按「了解，開始戰鬥」後倒數 3 秒繼續；同一個頭目之後不會再跳出（更新前已經遇過的頭目也不會再跳）。
- **完美閃避**：用衝刺穿過敵彈或頭目的線條、橫掃攻擊時算一次閃避：立即回復 1 點墨水，頭上跳出「完美閃避！墨水 +1」，畫面以角色為中心短暫放射狀模糊、閃一下白，並讓整個遊戲放慢到約 30% 再平順加速回原速（約 0.55 秒；0.8 秒內連續閃避只演出一次，但墨水照拿；開啟「動態減少」時只回墨水、不做慢動作與模糊）。
- **存檔**：所有進度（等級與經驗、金幣、成就與寶箱、外觀與配飾、已解鎖武器與遺物、最高分、圖鑑紀錄）存在瀏覽器／WebView 的 localStorage（鍵名 `inkfall.progress.v1`），設定存在 `inkfall.settings.v1`；每次存檔時會把上一份完好的存檔另存為 `inkfall.progress.bak` 作為備份，主存檔損毀時自動改讀備份。載入時新舊欄位用「合併＋補預設值」的方式處理，所以新版本新增的欄位不會影響舊存檔，更新不會洗掉進度（鍵名與格式不會更動）。Android 版存在 App 自己的 WebView 儲存空間，解除安裝或在系統設定「清除資料」會一併清掉，另外 App 開啟了系統的自動備份。設定中的「重置遊戲」會刪除全部存檔（含備份）。
- 開啟網頁時會先播放墨滴落下的加載動畫，分頁上有 INKRAGE 圖示。主選單左下角顯示目前版本號（例如 `beta v0.10.27`），每個版本的更新內容記錄在 [更新日誌.md](更新日誌.md)；所有卡牌、敵人、頭目、武器與小遊戲（含獎懲機率）的數值整理在 [數值表.xlsx](數值表.xlsx)，可下載後填寫「修改建議」欄。
- 主選單：選單集中在畫面右側約 1/3 的紙面欄位（標題、筆記本模式、課表模式、遺物、訓練場、成就、圖鑑；第一次玩某個模式時，按下模式按鈕會先自動跳出簡短的玩法說明（可選「開始遊戲」或「返回」）；之後可到「設定」右上角的「玩法說明」按鈕重看兩個模式的說明；兩個模式按鈕下方直接以小字顯示各自的最高分），左側 2/3 的中央是面向玩家的主角，鏡頭會緩慢環繞；「外觀與武器」按鈕就在主角正下方（裡面有顏色、配飾、武器三個分頁；武器分頁是一把武器一列的清單，隨機在最上面，點已解鎖的武器直接裝備，點上鎖的武器可用金幣提前解鎖；目前武器的詳細效果固定顯示在清單下方，主選單在這個按鈕下方顯示目前裝備的武器），左上角（離畫面邊角留了一點距離）是一個細長框：左邊是設定（齒輪圖示），中間一條淡灰分隔線，右邊顯示目前等級與較短的經驗進度條，點右半邊可打開「等級詳情」。選單與左側之間的手繪分隔線會緩緩擺動，並有墨滴沿線流下。

### 整局流程

- 課表模式每 5 頁為一幕（4 個課程房間＋1 個頭目房間）。
- 課表模式只有每幕的第 1、3、5 頁有選卡獎勵：第 1、3 頁從 2 張卡中選 1 張（可跳過）；第 5 頁擊敗頭目後進入圖書館，向兩位守卡人分別領一般牌（2 選 1）與特殊技（2 選 1），並從圖書管理員身邊三選一拿一件遺物。筆記本模式的頭目也一樣。擊敗頭目回復 4 點生命。
- 選卡時每張卡下方會顯示牌組中已有幾張；再拿一張就會合成時會以紅字提示。
- 強化過的卡牌有雙層內框、下方角落塗黑與星號標記（特殊技為紅色）。
- 陷阱圈與橡皮印章兵的墨印會在圈內靠近邊緣處顯示一圈黑色倒數，圈越短代表越快消失（陷阱圈不再在角色腳下顯示倒數條；其他敵人的墨漬不顯示倒數）。其他有持續時間的卡牌效果（連射、雙持、疾筆、反彈紙、時停等）會在角色腳下顯示一條倒數條與效果名稱，同時有多個效果時顯示最快結束的那個；分身的倒數條顯示在分身身上。
- 施放卡牌一律以按下施放當下的位置為起點，不會因為出牌動畫期間的移動而偏掉。
- 死亡即結束本局，顯示結算畫面後可重新開始。結算畫面像批改作業（破最高分時會蓋上「創新高分！」印章並放煙火、灑紙片；畫面最下方有一張撕過的不規則紙條「本局明細」，點一下紙條會帶點回彈地往上滑出、各列依序浮現，不會蓋滿整個畫面，內容超過一頁時上下滑動（或滾輪）瀏覽，以每一幕分區（幕與幕之間有虛線分隔）列出每一頁的類型、擊倒、出牌、用時、造成傷害、受到傷害、分數增減與該頁結束時的總分，點紙條外的空白處就收回去）：標題以印章蓋上、分數從 0 滾動到最終值、紅筆圈出評等（S／A／B／C／D，依本局總分決定；滑鼠移上去或觸控點一下可查看各評等的分數門檻）、破紀錄時貼上「新紀錄」標籤，各項數據以便條卡片翻出，經驗條會動態填滿並在升級時變紅；通關時灑下彩色紙片，被擦除時畫面流下紅墨。
- 敵人腳下會用和彈匣相同的刻度弧線顯示血量，剛失去的血量會短暫以紅色標示（精英敵人為紅色刻度）。
- 選卡獎勵時滑鼠移到卡上會顯示效果。
- 輔助瞄準鎖定敵人時，敵人身上會出現旋轉的紅色鎖定框與頭頂箭頭，準心也會變紅；換彈時準心外圍會有一圈進度環（暫停時準心恢復原狀）。
- 傷害數字會彈出放大、大傷害與爆擊有放射線與紅色字。

### 音效與音樂

- 所有音效皆為即時合成（Web Audio），以紙筆質感為主：射擊是筆尖輕點、命中是悶響、擊殺是紙張撕裂、特殊技是紙張刷過後的重擊加上鐘聲般的餘音，並加上輕微殘響與壓縮讓整體更一致。
- 背景音樂同樣全部由程式即時生成（不使用任何外部音檔或網路素材）：每首曲子由和弦進行、鋪底和弦、貝斯、琶音、自動作曲的旋律（固定種子產生 A／B 兩段，依 A A B A 循環）與合成鼓組成。共有 6 首：主選單（慢速、多利安調式）、商店與休息等非戰鬥頁（輕快大調）、事件小遊戲（跳躍的利底亞調式）、訓練場、一般戰鬥（132 BPM 小調）、頭目戰（148 BPM 弗里吉亞調式、更重的鼓與貝斯）。切換場景時會淡入淡出交叉切換，打開暫停選單時音樂會自動壓低（從暫停進入設定或圖鑑則不會）。角色倒下、畫面反黑的瞬間，音樂會被低通濾波悶住並變小聲、停止演奏新的音符，同時響起低沉下墜的重音、帶泛音的鐘聲與紙張撕裂聲。
- 音量分成主音量、音樂、音效三個滑桿，各自可點喇叭圖示快速靜音。

### 墨水與卡牌

- 擊殺敵人會獲得墨水（上限 10；在非戰鬥頁透過獎勵或商品補墨水時可以超過上限一次，例如 12 / 10，數字會變紅，已經超過上限時就不能再加），不同敵人給的量不同（以 0.5 為單位，例如塗鴉兵 1、墨團 1.5、橡皮怪 2、頭目 4，精英加倍），數值寫在圖鑑的敵人頁面；出牌需要消耗墨水（卡牌費用皆為整數）。墨水不足時點選或按快捷鍵選牌，卡牌會快速震動並閃紅提示，不會進入瞄準。
- 手牌 4 張，出牌 1 秒後補牌；抽牌堆用完會自動洗牌 2 秒，期間無法出牌；每次洗完牌獲得 +5 墨水。

網址加上 `?level=7` 可直接以指定等級遊玩（測試用）；`?mod=dark` 可強制房間特殊規則（dark／elite／hurry）。

網址加上 `?deck=all` 可以用全部卡牌作為牌組（測試用）；`?seed=數字` 可固定洗牌順序。

網址加上 `?quality=low`、`?quality=mid` 或 `?quality=high` 可以強制指定畫質。

## 本機執行

遊戲使用 ES modules，必須透過本機伺服器開啟，不能直接雙擊 `index.html`。

```
python -m http.server 8000
```

接著開啟 http://localhost:8000/

平板測試：電腦與平板連同一個 Wi-Fi，在平板瀏覽器開啟 `http://<電腦的區網 IP>:8000/`。
