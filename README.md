# INKRAGE

3D 手繪風射擊 × 牌組構築遊戲。整個世界像是用鋼筆和鉛筆畫在筆記本紙上，以 Three.js 製作，不需要任何建置步驟。

## 線上遊玩

https://archie-30.github.io/INKRAGE/

（需先在 GitHub 開啟 Pages，推送到 `main` 後會自動部署。）

## 操作方式

### 桌機

| 按鍵 | 功能 |
| --- | --- |
| W A S D／方向鍵 | 移動 |
| 滑鼠 | 瞄準 |
| 滑鼠左鍵（按住） | 射擊（靠近敵人時會輔助鎖定） |
| R | 裝填（彈匣 12 發，打完會自動裝填） |
| Space／滑鼠右鍵 | 衝刺（衝刺期間與之後約 0.3 秒無敵） |
| 1／2／3 | 選取對應位置的卡牌（3 為特殊技格）；無目標卡直接出牌 |
| 左鍵點戰場 | 對選中的卡指定位置／方向施放（地面會顯示虛線預覽） |
| 再按同一個數字鍵 | 立即朝滑鼠位置施放 |
| 鉛筆牆 | 選牌後按住左鍵在地上畫出牆的路徑，放開即長出牆 |
| Esc／右鍵 | 取消瞄準 |
| Tab | 查看牌組（抽牌堆／棄牌堆，遊戲暫停） |
| F | 與地圖裡的角色或寶箱互動；站在門裡時確認進入下一頁 |

> 用電腦遊玩時，卡牌與牌堆只能用快捷鍵操作（滑鼠點卡牌不會出牌）；出牌後新抽的牌會補回原本的位置。
| F2 | 切換畫質（低／中／高） |
| F3 | 顯示除錯資訊（FPS、繪製呼叫、三角形數） |
| Esc／P | 暫停（Esc 在瞄準卡牌時為取消瞄準） |

### 平板（觸控）

| 操作 | 功能 |
| --- | --- |
| 左下固定搖桿 | 移動（第一次觸碰螢幕後才會顯示） |
| 右下固定搖桿（雙圈） | 手指在內圈（虛線圈內）只轉向瞄準、不射擊；推到外圈（紅色細圈）才會射擊，內圈大小可調 |
| 右搖桿周圍的技能鍵 | 仿手遊技能鍵，繞著右搖桿排成一圈：衝刺、卡牌 1、卡牌 2、特殊技（顯示卡牌圖示與費用，墨水不足時變淡） |
| 點技能鍵 | 不需瞄準的牌（例如紙盾）直接施放；其他牌選取後用右搖桿或拖曳技能鍵瞄準，再點一次取消（觸控時中間的手牌只供查看，不能點選）。按住技能鍵時衝刺鍵會變成紅色叉叉，手指滑到叉叉上放開就取消施放 |
| 互動鍵 | 可以與角色、寶箱、音鈴互動或站在門裡時，衝刺鍵會變成「互動」鍵，並會微微晃動提醒可以按；戰鬥中太久（約 10 秒）沒用技能時，可以出的技能鍵會輪流晃一下，旁邊還會擴散出像音波一樣的圓環提醒（訓練場不會） |
| 按住技能鍵拖曳 | 直接瞄準，地上顯示虛線預覽，放開即施放 |
| 選牌後拖曳右搖桿 | 地上顯示虛線預覽，放開搖桿即施放（搖桿變紅色表示施放模式） |
| 選牌後點一下右搖桿 | 自動瞄準最近的敵人施放 |
| 鉛筆牆 | 選牌後用右搖桿擺放，或用手指在地上畫出路徑 |
| 暫停時點卡牌／牌組中點卡牌 | 顯示卡牌效果；牌組中點空白處收起說明，牌多時可上下滑動，按「關閉」才會離開牌組 |
| 選卡獎勵 | 點一下顯示效果，再點一次選擇 |
| 點抽牌堆 | 查看牌組 |
| 右上角「暫停」按鈕 | 暫停 |
| 三指同時觸碰 | 顯示除錯資訊 |

請橫向持握裝置。手機上鏡頭會比電腦更靠近角色、角度稍低。手機等小螢幕上整個介面會依畫面大小等比例縮小，描邊也會自動變細，避免角色糊成一片。在觸控與鍵盤滑鼠之間切換時，畫面上方會跳出「已切換至觸控操作／鍵盤滑鼠操作」的通知（剛進入遊戲第一次觸控時不會跳出）；所有介面上的操作說明也會跟著目前使用的裝置切換（觸控時只顯示點一下、拖曳、互動鍵等說法，鍵鼠時才顯示按鍵與滑鼠說明）。第一次觸碰時會嘗試進入全螢幕；若瀏覽器不支援全螢幕（例如 iPhone 上的瀏覽器），會自動停用全螢幕設定並跳出提示，建議改用 Chrome。效能：遊戲第一次啟動時會量測螢幕更新率與裝置等級，旗艦手機（120Hz 螢幕、8 核心以上）預設高畫質 120 FPS，一般手機預設中畫質 90 FPS（60Hz 螢幕則 60），較弱的裝置預設低畫質；之後可在設定自行調整。遊戲中會即時監測幀率，跟不上目標時先自動降低 3D 畫面的渲染解析度（介面文字與按鈕維持清晰，順暢時再慢慢調回），降到下限仍不順才會自動降一級畫質。開啟開發者模式時右上角會顯示 FPS／目標、動態解析度、繪製呼叫與實際渲染解析度，方便在手機上實測。角色腳邊的地上有一個小三角形指向目前面向的方向；觸控時另有一條很淡的虛線畫出面向方向，方便瞄準（可在設定「觸控方向輔助」關閉）。

### 模式與成長

- **筆記本模式**：3 幕，每幕 6 頁加 1 頁頭目。頭目每次都從五隻中隨機抽出一隻（同一局不重複）：巨型墨瓶、剪刀魔、墨跡之書、考卷魔王、巨筆暴君。所有頭目血量降到門檻（巨筆暴君三分之一、其他一半）時會鎖血、播放進化動畫（邊旋轉邊變大、身體轉紅、頭上冒出台詞，期間刀槍不入），接著進入第二型態並加入新的招式；頭目血條上的紅色刻度就是進化門檻。越後面的幕，頭目攻擊越頻繁、血量越多，第 2 幕起還會定時召喚小兵（第 2 幕塗鴉兵，第 3 幕再加摺紙鳥與散彈兵）。每一頁都是一張實際走進去的地圖：
  - 過關後上方的門打開，門後的小空間裡有發光旋轉的紙頁並冒出光點；走進門裡按 F（觸控點提示框）確認，畫面四周出現黑色集中線指向門口，門口的白光越來越亮、擴散到整個畫面全白，接著下一頁從白紙上畫出來（轉場期間遊戲暫停）。站在門裡時提示框會附上那一區的簡短介紹。門上標示的頁面類型要過關後才會顯示。
  - 一般頁面上方會有 2～3 扇門，門上標示通往的頁面類型，可以先看好再選（還沒過關時，畫面外的門不會顯示方向提示）：一般戰、精英戰（第 2 幕起）、挑戰頁、寶箱頁、文具店、事件頁（小遊戲）、奇遇頁、修正液休息；每次至少有一扇是戰鬥。下一頁是頭目時只會有一扇門。
  - 進入每一頁時，畫面上方會出現目前這一幕的進度條（一條線、一頁一個點，最後的菱形是頭目頁），已經走過的點塗黑、目前所在頁是紅點並跳到新的一頁，幾秒後自動淡出；按暫停時暫停畫面上方也會顯示。右上角暫停鍵旁邊用大字顯示目前分數，加分或扣分時會震動、加分時放大變紅。
  - 非戰鬥頁（文具店、事件、奇遇、休息、寶箱）角色會收起武器、不能射擊；如果遇到伏擊，卡牌介面滑上來的同時角色會播放拿出武器的動畫。
  - 獲得、移除、升級或失去升級的卡牌，都會在畫面中央播放接近全螢幕的卡牌動畫（新卡從下方飛入再收進牌堆、被移除的卡會被撕成兩半掉落、升級時卡牌蓄力發光後變成強化版；一次升級兩張卡時兩張會左右並排一起播放，不用看兩次；升級時畫面中間不再另外跳出「已升級」的小框），可以點一下略過。自選升級哪一張卡時，升級後效果的說明放在卡牌下方獨立的紙條裡（最多兩行），不會被卡牌或按鈕擋住。事件、寶箱、商店等結果則只以文字顯示在右上角分數下方（沒有外框），加分會先跳出「+多少分」飛進分數再加上去。
  - **挑戰頁**：戰鬥加上條件（不受傷／限時／不使用卡牌），達成可加分並從稀有卡中挑一張，失敗則是一般獎勵。
  - **寶箱頁**：三個寶箱只能開一個，分別是稀有卡、補給，以及會咬人的假寶箱（伏擊戰）。
  - **文具店**：商品直接陳列在老闆前方的展示台上（每樣商品上方有名稱與價格牌，分數不夠時價格變紅；老闆正前方不會生成擺設擋住；靠近商品時的介紹彈窗會蓋在其他價格牌上方），走到商品旁按 F（觸控點提示框或互動鍵）就能用分數購買，老闆會在頭上的對話框說話（歡迎光臨、分數不夠、謝謝惠顧等）；和老闆說話或買過一樣東西後上方的門就會打開。每次進去會從 9 種商品中隨機上架 3 種（不會跟上一間一樣）：挑一張卡（三選一，不能跳過）、稀有卡包（三張特殊技選一）、升級一張卡、隨機加工（隨機升級 2 張）、OK 繃（+2 生命）、大包紗布（+4 生命）、修正帶（挑一張卡移除）、補充墨水（+4 墨水）、武器交換（三把武器選一把換上），花掉的分數會從結算扣除。
  - **事件頁（小遊戲）**：每次都是一個小遊戲，不能跳過。場上先擺好遊戲的道具，和角落的主持人說話時，它會用一張筆記紙簡短說明玩法，按「開始！」就開始；畫面上方會顯示目前進度與剩餘秒數。過關會從獎勵池隨機抽一項（加分、選一張卡、稀有卡、回血、墨水、隨機升級卡……），失敗則從懲罰池隨機抽一項（扣血、扣分、被移除一張卡、卡片降級、下一場變精英戰、伏擊戰……），同一種獎懲不會連續抽到兩次；結果顯示在右上角分數下方，主持人也會在頭上的對話框說一句話（過關時誇獎，失敗時說「好可惜……」之類的話；主持人在畫面外時對話框會貼在畫面邊緣）。16 種小遊戲輪流出現（剛玩過的會先避開，數值隨幕數變難）：
    - 記憶音鈴：每次隨機敲 4～6 下，看音鈴亮起的順序，再走到音鈴旁按 F（觸控按互動鍵）照順序敲響；音鈴會擺動、發出鐘聲並震動畫面。
    - 塗鴉靶場：限時用武器打倒 6 個紙靶（主持人是戴帽子的教練，不是靶）。
    - 描線練習：沿著地上的虛線從起點走到終點，偏離太遠就失敗。
    - 推橡皮擦：用身體把大橡皮擦推進紅圈。
    - 倒墨水：站在踏板上墨水就會上升，在紅線附近離開踏板，溢出就失敗。
    - 踩格子：把每一格白色地板都踩黑，同一格不能踩兩次，也不能踩打叉的墨漬格；格子更多、時間更短（一定有解）。
    - 找不同：說明完開始後，兩張圖上的東西才會一個個蹦出來；在 B 圖上站到和 A 圖不一樣的格子裡停一下圈出來（找到的格子變紅並畫圈、錯的格子變黑打叉），可以錯一次。
    - 翻牌配對：站在牌上翻牌，一次兩張，配錯太多次就失敗（可容錯次數減少）。
    - 躲墨雨：一朵墨雲飄在場地上空，地上會先出現越來越大的影子，墨滴落下時站在影子裡就會被淋到；被淋到太多次就失敗，撐到時間結束就成功（越後面掉得越頻繁、影子越快落下、一次掉兩滴的機率也越高，部分墨滴會瞄準你的位置；時間一到場上的影子與墨滴會全部清空）。
    - 骰子賭運：站上「大」或「小」下注，猜中骰子點數的大小。
    - 紙飛機：站在發射台上瞄準垃圾桶，看準力道條按 F（觸控按互動鍵）丟出，三次機會。
    - 書本迷宮：更大的 8×5 迷宮、時間更短，開始前地板上不會顯示路線，書牆從起點向外依序升起，結束時依序沉下去，限時走到紅色星星。
    - 節奏踩點：音符從天上掉進三個圈圈，落地時站在那個圈裡接住它。
    - 跟著影子走：記住影子走過叉叉的順序，再照順序踩一遍；影子走過的地方會留下一條逐漸淡去的紅色墨跡。
    - 滾彈珠：用身體把彈珠撞進紅圈，避開黑洞。
    - 猜杯子：杯子數量隨機 3～5 個（後面的幕更容易抽到多杯）；記住墨珠在哪個杯子底下，杯子打亂後站到你猜的杯子前面。
  - **奇遇頁**：8 種奇怪遭遇輪流出現（打翻的墨水瓶、會說話的橡皮擦、塗鴉牆、同學的筆記、扭蛋機、削鉛筆機、打翻的咖啡、塗鴉幽靈），每個選項都有代價（例如失去生命、扣分、被隨機移除一張卡），有的會觸發伏擊戰；選完後畫面中間偏上會列出得到與失去的東西（扭蛋會顯示扭到什麼；扭蛋機選項的每個機率各自一行）。
  - **修正液休息**（出現機率較低）：回復生命（生命 4 以下固定 +2，否則隨機 +1～2），或選一張卡升級。
  - 非戰鬥頁不會顯示卡牌介面（按 Tab 可看到全部卡牌都在抽牌堆）；如果遇到伏擊，卡牌介面會滑上來，之後就一直保留。
  - 非戰鬥頁有好幾張地圖輪流出現，而且每次進去格局都會變：角色（或三個寶箱的排法）會出現在不同位置，周圍的擺設也會隨機換位、旋轉，整張圖還可能左右翻轉；堆疊的書本與紙團都有碰撞，角色不會再走進去。靠近角色或寶箱後按 F（觸控點提示框或互動鍵）互動，選項會出現在一張貼著膠帶的筆記紙上（標題、說明與便條紙選項都用大字）；至少要互動過一次，上方的門才會打開。
  - 第 3 幕頭目倒下後上方會開兩扇門：「收筆結算」或「繼續寫下去」進入延長寫作（強度接續無盡模式、每 5 頁一隻頭目），分數持續累積。最高分顯示在主選單「筆記本模式」按鈕下方。
- **無盡模式**：頁數無限、越來越難，每 5 頁為一幕（前 4 頁打一般敵人、第 5 頁打隨機頭目），每一幕的第 1、3、5 頁有選卡獎勵，以分數計算並記錄最高分。清除後走進上方發光的門並按 F 前往下一頁。
- **循序漸進**：第一頁只有塗鴉兵，之後大約每 2 頁加入一種新敵人（墨團 → 散彈兵 → 橡皮印章兵 → 墨雲 → 摺紙鳥 → 圓規手 → 橡皮怪），出現時標題會提示「新敵人」；無盡模式每 3 頁加入一種。為了畫面不要太亂，每一頁最多只出現 3 種一般敵人，並優先換上和上一頁不同的種類，讓各種敵人輪流登場。
- 切換瀏覽器分頁或視窗失去焦點時會自動暫停，同時放開所有按住的按鍵、搖桿與卡牌；暫停或設定介面顯示時（包含淡出動畫期間），點擊與放開都不會穿透到背後的卡牌或按鈕。
- 暫停選單：繼續、查看牌組、圖鑑、設定、結算並回到主選單（先顯示本局結算再回到主選單）。戰鬥中（或有計時的小遊戲中）按「繼續」後會先回到遊戲畫面並在中央倒數 3 秒（非戰鬥狀態與沒有計時的小遊戲則直接繼續，不倒數），倒數期間可以先調整搖桿方向，但角色不會移動也不能射擊或出牌，倒數結束立刻接續遊戲。暫停或查看牌組時鏡頭不會跟著滑鼠移動。
- **等級**：共 10 級，每局結束依表現獲得經驗，升級會解鎖新卡牌與武器（升級所需經驗比以前多，大約要玩十幾到二十多局才會滿級）。結算後回到主畫面時，如果這段期間有升級，會播放「等級提升！」印章動畫，新解鎖的卡牌會一張張翻面飛出來，點一下繼續。主選單等級框打開的「等級詳情」會直接停在目前等級那一列。卡牌一解鎖就會進入獎勵卡池，從第一幕第一頁起就有機會抽到（沒有依幕數限制）。圖鑑中的「等級 N 解鎖」就是該卡需要達到的等級。
- **開發者模式**：設定中點開後需輸入開發者密碼才能開啟（畫面上會跳出數字鍵盤，手機也能直接點）；開啟後，所有卡牌與敵人圖鑑立即解鎖、獎勵可抽到所有卡；開啟期間不會累積經驗與最高分，關閉後回到原本的等級與紀錄，如果當時選的武器在目前等級還沒解鎖，會自動換回鋼筆。
- **手牌**：2 張一般牌＋1 格特殊技；特殊技格已滿時，抽到的特殊技會直接進入棄牌堆。
- **卡牌合成**：牌組中有 3 張相同的一般牌時會播放升級動畫，合成為 1 張強化版；3 張相同的特殊技也會合成，效果不變但費用 -1。
- 吸墨紙選取後會在角色周圍畫出作用範圍的虛線圈：鍵鼠再按一次數字鍵或點左鍵施放；觸控按住技能鍵往任意方向滑出就立即施放。
- 雙持（特殊技，6 秒）期間螢光筆也會左右手各射出一道光束，兩道光束平行，瞄準點（含輔助瞄準）在兩道中間。墨漩渦爆炸時如果只炸到 1 個敵人，改為造成 100 傷害（強化版 140）。
- 頭目倒下時場上剩下的敵人會直接消失，不再跳出一大串傷害數字。
- **嘲諷**：頭目與精英敵人活著的時候，會不時在頭上冒出紅色對話框嘲諷你（例如「就這？」），共有 36 句隨機輪替，不容易重複。
- **頭目戰墨水**：頭目關卡中場上會不定時掉落少量墨水（每次 1 點，場上最多 2 個）。
- **場景**：墨水桶（射爆會範圍爆炸）、紙箱（打破可能掉落墨水或生命），部分房間有特殊規則（白霧：以玩家為中心之外的區域被擦淡；精英；急速）。
- 按 Esc 暫停時，滑鼠移到手牌上可以查看卡牌效果；點抽牌堆／棄牌堆可查看整副牌組，牌組中的卡同樣可以滑鼠移上去看效果。

### 選單與設定

- 開啟網頁時會先播放墨滴落下的加載動畫，分頁上有 INKRAGE 圖示。主選單左下角顯示目前版本號（例如 `beta v0.9.32`），每個版本的更新內容記錄在 [更新日誌.md](更新日誌.md)；所有卡牌、敵人、頭目、武器與小遊戲（含獎懲機率）的數值整理在 [數值表.xlsx](數值表.xlsx)，可下載後填寫「修改建議」欄。
- 主選單：選單集中在畫面右側約 1/3 的紙面欄位（標題、筆記本模式、無盡模式、武器、訓練場、成就、圖鑑；兩個模式按鈕下方直接以小字顯示各自的最高分，「武器」按鈕下方顯示目前裝備的武器），左側 2/3 的中央是面向玩家的主角，鏡頭會緩慢環繞；「角色外觀」按鈕就在主角正下方，左上角（離畫面邊角留了一點距離）是一個細長框：左邊是設定（齒輪圖示），中間一條淡灰分隔線，右邊顯示目前等級與較短的經驗進度條，點右半邊可打開「等級詳情」。選單與左側之間的手繪分隔線會緩緩擺動，並有墨滴沿線流下。
- **武器**：主選單「武器」可選擇每局使用的主武器（不列入圖鑑），每把都有示範動畫、數值條與說明（實際數值直接寫在數值條左邊），角色手上的武器外觀也會跟著換。最下面的「隨機」在解鎖 2 把以上武器後開放（示範區會平順地輪播候選武器，轉到框正中間時放到最大）：每局開始時從已解鎖的武器隨機挑一把，而且不會和上一局用的武器相同。升級會解鎖更多武器（上帝視角可全部解鎖）：

  | 武器 | 解鎖 | 傷害 | 射擊間隔 | 彈匣 | 特色與子彈外觀 |
  | --- | --- | --- | --- | --- | --- |
  | 鋼筆 | 1 | 10 | 0.12 秒 | 12 | 均衡單發，黑色墨水彈 |
  | 自動鉛筆 | 2 | 5 | 0.09 秒 | 26 | 高射速、低傷害，細小的灰色筆芯 |

  所有武器中只有毛筆與圓規能打掉敵彈，其他武器的子彈會直接穿過敵彈。每把武器有各自的射擊音效、槍口閃光與後座力，裝備或切換武器時角色會把武器轉一圈拿出來。「連射」等加速效果有射速上限，不會讓武器快到失控。連續命中時傷害數字不再合併成一個（以前看起來像兩倍傷害），遊戲沒有爆擊系統，紅色帶驚嘆號的數字只代表打中頭目弱點。

- **新手教學**（第一次進入遊戲時會直接帶進教學場地，之後可從主選單的設定裡再玩一次）：會進入專屬的教學場地，一律使用鋼筆，一步一步親自操作：移動（走進 3 個紅圈）、武器射擊（打倒 3 隻塗鴉，說明換彈）、閃避無敵（用衝刺穿過噴彈兵的子彈 2 次）、施放技能（出 2 張技能牌，同時要選好技能後取消施放 1 次）、查看牌組與卡牌效果（打開牌組並查看 1 張卡牌的詳細效果）、特殊技（施放 1 次，等技能真正打出去之後才算完成），接著是遊戲機制、看懂敵人預警、卡牌升級（可以按「合成看看」實際看一次合成動畫）、解鎖與收集（說明升級後到「武器」與「圖鑑」查看新卡牌與武器），接著介紹獎勵與裝扮（寶箱、成就與墨點、快速解鎖、復活與角色外觀），最後以「還有許多關卡等你去探索，祝你旅途順利！」與彩色紙片結尾並回到主畫面。每一步都有示意動畫，動作步驟的動畫角落還會依目前操作方式畫出對應的按鍵或搖桿／按鈕示範；練習時畫面上方有目標條（同時有兩個目標時分兩行）與進度圓點，完成時蓋上「完成！」印章，剩下的練習目標會直接消失、不會跳出傷害數字。某個練習超過 30 秒沒完成會再跳一次該步驟的說明（標示「再看一次」，按「繼續練習」保留進度）；教學中技能鍵不會因為太久沒出牌而震動提醒。教學中生命與墨水無限；暫停選單的最後一個按鈕改為「跳過教學並回主畫面」。
- **訓練場**：可以試用所有已解鎖的卡牌。一進場先選初始手牌（2 張一般牌＋1 張特殊技，或按「隨機」；下方「回主畫面／隨機／放入手牌」三個按鈕排在一起，按錯可以直接回主畫面；選隨機時補牌方式自動改為隨機抽牌，手動選牌則為固定補牌）。訓練場設定與 Tab 選牌畫面開啟時遊戲會暫停，訓練資訊以遊戲時間計算。訓練場上方有兩扇門：左邊「回主畫面」（以進門動畫回到主選單），右邊「測試小遊戲」（打開 16 種小遊戲的選單，每一格左邊都有會動的小縮圖方便辨認，選單開關時會平順地淡入上浮、淡出下沉，選了之後跑一般進頁的過場動畫進入那個小遊戲）。測試小遊戲的房間上方有三扇門，一進去就開著，隨時可以切換或離開：左邊回訓練場、中間再選另一個小遊戲、右邊回主畫面（小遊戲不會有獎懲）。訓練場設定的地圖改為下拉選單（每個選項都有小地圖預覽，障礙物較清楚），並移除了「離開訓練場」按鈕。墨水與生命無限，畫面左上角改為「訓練資訊」框（總傷害、近 5 秒每秒傷害、最高單次、最後一擊、擊倒數、出牌數、被擊中次數、場上敵人）。
  - 按 Tab 或點抽牌堆可重新選卡；特殊技用掉後會自動補上（固定模式補回選的那張，隨機模式隨機補一張）。
  - 按 Esc（或右上角鈕）開啟「訓練場設定」：地圖（下拉選單，每個選項附小地圖）、武器（下拉選單，可切換任一已解鎖武器）、障礙物、敵人會攻擊、敵人無限血量、無限彈藥（預設開）、補牌方式（固定補回選的牌／照常隨機抽牌）、頭目（下拉選單，第一個選項是「無」，一次只能召喚一隻，召喚出的頭目會出現在場地正中央；未遇過的頭目顯示問號、無法選擇；召喚的頭目在畫面上方同樣有血條），以及敵人設定——每種敵人都有「一般」與「精英」兩組加減（總數上限 12），或開啟「隨機生成敵人」並設定數量與精英機率。未遇過的敵人無法選，塗鴉兵永遠可選。被打倒的敵人一律會重生。地圖、武器、障礙物與各項開關在這次遊玩中會被記住（重新開啟遊戲才恢復預設）；敵人與頭目設定則每次進入訓練場都恢復預設值（頭目無、三隻塗鴉兵）。
- **角色外觀**：主選單的「角色外觀」分成「顏色」與「配飾」兩個分頁，兩個分頁最上面都是 4 格「自訂套組」：點空格直接儲存目前外觀（含配飾）；點已存的格子會切成左右兩個按鈕，左邊「套用」、右邊「覆蓋」。一開始只解鎖少數基本色（淺灰、紙白、炭灰、石墨等灰階與墨黑），共 20 種布色與 8 種點綴色，其他顏色與配飾要靠結算寶箱、成就寶箱獲得，或花墨點快速解鎖（顏色 2 墨點、配飾 5 墨點，上鎖的格子點了會跳出確認視窗）。12 套「配色套裝」是含配飾的整套造型，卡片左上角顯示已擁有幾個部件；點還沒湊齊的套裝會跳出視窗列出缺少的每個顏色與配飾和價格，可按「全部解鎖」一次買齊並直接穿上。底部的「隨機」按鈕會從已擁有的顏色與配飾隨機搭一套（骰子會轉動）。配飾分頭飾（墨滴帽、貝雷帽、紙皇冠、竹蜻蜓帽、耳機、貓耳、紙摺帽）、臉飾（圓眼鏡、單片眼鏡、眼罩、八字鬍、OK 繃）、頸飾（圍巾、領結、領帶、鈴鐺項圈、串珠項鍊、紙褶領）、背飾（小背包、披風、紙翅膀、大書包、鉛筆筒、卷軸），每個部位都可以選「不戴」；配飾會跟著帽子／小物的顏色上色，外框使用細線。鏡頭拉近後角色會置中在面板右側的預覽區，按住滑鼠左鍵（或手指）左右拖曳可旋轉，設定自動儲存。
- **墨點與成就**：主選單左上角等級框右邊顯示持有的墨點（點一下可打開成就頁）。「成就」按鈕在「圖鑑」上方，共 30 個成就（例如衝刺閃過攻擊 10 次、擊倒 100 個敵人、無傷擊敗頭目），每個都有進度條，達成時畫面上方會跳出提示並獲得 1 墨點（在選單中達成的成就，例如儲存自訂套組、收集外觀、升級，也會即時跳出）；成就頁最上面的總進度條每 5 個成就有一個寶箱（共 6 個），寶箱內含 2 個顏色或配飾。墨點可用來快速解鎖顏色（2）、配飾（5）、提前解鎖武器（每把 15，在武器頁按「提前解鎖」），或在生命歸零時復活：會跳出復活視窗，可選擇花 1～10 墨點（每 1 墨點復活後有 1 點生命），每局限用一次。開發者模式下不會累積成就與寶箱。
- **結算寶箱**：筆記本／無盡模式結束時依表現給 0～3 個顏色或配飾（筆記本：清除 5 頁戰鬥、擊敗頭目、寫完整本各 +1；無盡：到達第 5、12、20 頁各 +1），本局每升一級再多 1 個配飾（等級獎勵）；結算畫面按鈕列右邊會出現寶箱，點開有搖晃、開蓋、物品飛出的動畫（沒開就離開也會先播放）。全部收集完後多出的獎勵會換成墨點。
- **特殊技演出**：施放特殊技時遊戲會暫停，播放約 1.7 秒的全螢幕手繪演出，演出結束的瞬間（伴隨震撼的重擊音效與畫面震動）才真正發動技能。演出內容對應技能效果（例如紅墨處決先瞄準再劃叉擊碎敵人並跳出傷害數字、重畫讓三張卡的費用變成紅色的 0 並蓋上 FREE、墨漩渦把敵人吸進去再爆炸、百筆齊發的筆會追蹤飛向敵人、定格把敵人與子彈凍結（頭目也會在時間內完全定格）、回聲免費再施放一次你上一張使用的特殊技（演出標題顯示「回聲：技能名稱」，背景播放被複製的那張特殊技的演出並加上四邊霧化效果）、墨暴的閃電劈中敵人）；另外還有：卡牌像印章般甩上畫面、放射速度線、命中瞬間閃白並噴濺墨點，結束時名稱紙條撕成兩半退場；背景依技能不同（紅墨處決的紅色大叉、重畫的橡皮擦與重畫箭頭、墨水海嘯的墨浪、墨漩渦的漩渦、百筆齊發的筆雨、巨筆一劃的巨筆、定格的暫停框與裂痕、墨暴的烏雲與紅色閃電），期間遊戲短暫慢動作；開啟「動態減少」時只顯示名稱。
- 圖鑑分為「一般牌／特殊技／敵人／頭目」四頁，可用滾輪或拖曳瀏覽。兩個卡牌頁上方可以依墨水費用篩選（全部／1 墨／2 墨……），篩選會在這次遊玩中保留，重新開啟遊戲後才清除。手機上「圖鑑」標題移到左上角與分頁同一列，卡牌一排顯示三張，也不再顯示「點擊查看施放示範」。列表只顯示一句簡述與費用、傷害、方式等重點標籤，點開後才列出完整效果與數據。點卡牌會放大並循環播放施放示範；點敵人會列出生命、速度、擊殺墨水等數值（可切換成精英版本），並以動畫示範每一種攻擊方式與各自的傷害。一般牌可切換「基本／強化」預覽強化後的效果。每局一開始就在牌組裡的卡會標示「初始牌 ×張數」。還沒遇過的敵人只會顯示問號。
- 設定：右上角的「語言」下拉選單（展開與收起有動畫）可切換繁體中文／English（整個遊戲的文字都有完整英文翻譯，切換後立即生效）；第一次進入遊戲時、進入新手教學之前會先請你選擇語言，選好後下方會用選擇的語言提示之後可以在設定裡更改。其餘項目：主音量、音樂、音效三個音量滑桿（滑桿左邊的喇叭圖示點一下即可快速靜音，再點一次恢復，靜音時圖示變紅並打叉）、畫質（低／中／高）、幀率上限（60／90／120，第一次進入遊戲時依裝置效能與螢幕更新率自動選擇，放在畫質正下方）、畫面抖動（調整線條抖動的強度，左邊的圖示點一下可直接關閉，再點一次恢復；事件頁中小遊戲的大量道具本身不套用抖動，畫面不會太亂）、輔助瞄準（同時包含準星吸附與觸控方向虛線）、動態減少（關閉畫面震動、頓幀、慢動作、線條抖動與強烈閃光；開啟時「畫面抖動」自動歸零，關閉時恢復成開啟前的數值；特殊技演出仍會播放背景動畫，只是拿掉速度線、閃白與震動）、全螢幕（預設開，第一次點擊或按鍵時自動進入瀏覽器全螢幕；Chrome／Edge 在全螢幕中按 Esc 會打開暫停選單、長按 Esc 才離開全螢幕，其他瀏覽器按 Esc 離開全螢幕時會自動暫停）、繼續前倒數（預設開，關閉後從暫停繼續時不倒數 3 秒）、開發者模式，會自動儲存在瀏覽器。「重置遊戲」按鈕只在主選單打開的設定裡出現，需連按三次（確定要清除所有進度？→ 再按一次以重置 → 跳出最後確認視窗，警告此操作無法復原），在視窗按「確定重置」後畫面被墨水淹沒，所有存檔（等級、墨點、成就、外觀、解鎖武器、最高分、圖鑑紀錄與設定）都會刪除並重新載入遊戲，視為第一次遊玩；中途點其他地方或按取消即放棄。「離開」與「結算」類按鈕滑鼠移上去時會變成淺紅色背景。「觸控設定」按鈕會打開獨立頁面，調整搖桿大小、水平位置、高度、瞄準內圈大小與技能鍵大小（畫面上即時預覽搖桿與技能鍵，每個滑桿右邊都有單獨恢復預設的按鈕，也可一鍵全部恢復預設）。下方的「新手教學」按鈕（只在主選單打開的設定裡出現）會進入教學場地。每一項旁邊的 ⓘ 滑鼠移上去（觸控點一下，再點一次收起）會說明這項在調整什麼。
- 畫質三段的解析度相同（介面文字與按鈕在任何畫質都清晰），差別在渲染細節：「低」關閉紙紋顆粒、角色粗外框與網紋陰影，改用較簡單的描邊、關閉畫面線條晃動，並減少粒子與地面墨痕；「中」保留外框與陰影、使用較簡單的描邊並減少粒子；「高」開啟全部效果。平板預設為「中」。

### 整局流程

- 無盡模式每 5 頁為一幕（4 個戰鬥房間＋1 個頭目房間）。
- 無盡模式只有每幕的第 1、3、5 頁有選卡獎勵：第 1、3 頁從 2 張卡中選 1 張（可跳過）；第 5 頁擊敗頭目後分成左右兩區，左邊一般牌 2 選 1、右邊特殊技 2 選 1（保證有特殊技），兩區可各選一張再按確定，每區右上角也有「這區不選」按鈕可單獨跳過該區。擊敗頭目回復 4 點生命。
- 選卡時每張卡下方會顯示牌組中已有幾張；再拿一張就會合成時會以紅字提示。
- 強化過的卡牌有雙層內框、下方角落塗黑與星號標記（特殊技為紅色）。
- 陷阱圈與橡皮印章兵的墨印會在圈內靠近邊緣處顯示一圈黑色倒數，圈越短代表越快消失（陷阱圈不再在角色腳下顯示倒數條；其他敵人的墨漬不顯示倒數）。其他有持續時間的卡牌效果（連射、雙持、疾筆、反彈紙、時停等）會在角色腳下顯示一條倒數條與效果名稱，同時有多個效果時顯示最快結束的那個；分身的倒數條顯示在分身身上。
- 施放卡牌一律以按下施放當下的位置為起點，不會因為出牌動畫期間的移動而偏掉。
- 死亡即結束本局，顯示結算畫面後可重新開始。結算畫面像批改作業（破最高分時會蓋上「創新高分！」印章並放煙火、灑紙片；畫面最下方有一張撕過的不規則紙條「本局明細」，點一下紙條會帶點回彈地往上滑出、各列依序浮現，不會蓋滿整個畫面，內容超過一頁時上下滑動（或滾輪）瀏覽，以每一幕分區（幕與幕之間有虛線分隔）列出每一頁的類型、擊倒、出牌、用時、造成傷害、受到傷害、分數增減與該頁結束時的總分，點紙條外的空白處就收回去）：標題以印章蓋上、分數從 0 滾動到最終值、紅筆圈出評等（S／A／B／C／D，依本局總分決定；滑鼠移上去或觸控點一下可查看各評等的分數門檻）、破紀錄時貼上「新紀錄」標籤，各項數據以便條卡片翻出，經驗條會動態填滿並在升級時變紅；通關時灑下彩色紙片，被擦除時畫面流下紅墨。
- 敵人腳下會用和彈匣相同的刻度弧線顯示血量，剛失去的血量會短暫以紅色標示（精英敵人為紅色刻度）。
- 選卡獎勵時滑鼠移到卡上會顯示效果。
- 輔助瞄準鎖定敵人時，敵人身上會出現旋轉的紅色鎖定框與頭頂箭頭，準心也會變紅；換彈時準心外圍會有一圈進度環（暫停時準心恢復原狀）。
- 傷害數字會彈出放大、大傷害與爆擊有放射線與紅色字。

### 音效與音樂

- 所有音效皆為即時合成（Web Audio），以紙筆質感為主：射擊是筆尖輕點、命中是悶響、擊殺是紙張撕裂、特殊技是紙張刷過後的重擊加上鐘聲般的餘音，並加上輕微殘響與壓縮讓整體更一致。
- 背景音樂同樣全部由程式即時生成（不使用任何外部音檔或網路素材）：每首曲子由和弦進行、鋪底和弦、貝斯、琶音、自動作曲的旋律（固定種子產生 A／B 兩段，依 A A B A 循環）與合成鼓組成。共有 6 首：主選單（慢速、多利安調式）、商店與休息等非戰鬥頁（輕快大調）、事件小遊戲（跳躍的利底亞調式）、訓練場、一般戰鬥（132 BPM 小調）、頭目戰（148 BPM 弗里吉亞調式、更重的鼓與貝斯）。切換場景時會淡入淡出交叉切換，打開暫停選單時音樂會自動壓低（從暫停進入設定或圖鑑則不會）。角色倒下、畫面反黑的瞬間，音樂會被低通濾波悶住並變小聲、停止演奏新的音符，同時響起低沉下墜的重音、帶泛音的鐘聲與紙張撕裂聲。
- 音量分成主音量、音樂、音效三個滑桿，各自可點喇叭圖示快速靜音。

### 墨水與卡牌

- 擊殺敵人會獲得墨水（上限 10；在非戰鬥頁透過獎勵或商品補墨水時可以超過上限一次，例如 12 / 10，數字會變紅，已經超過上限時就不能再加），不同敵人給的量不同（以 0.5 為單位，例如塗鴉兵 1、墨團 1.5、橡皮怪 2、頭目 4，精英加倍），數值寫在圖鑑的敵人頁面；出牌需要消耗墨水（卡牌費用皆為整數）。墨水不足時點選或按快捷鍵選牌，卡牌會快速震動並閃紅提示，不會進入瞄準。
- 手牌 4 張，出牌 1 秒後補牌；抽牌堆用完會自動洗牌 2 秒，期間無法出牌。

網址加上 `?level=7` 可直接以指定等級遊玩（測試用）；`?mod=dark` 可強制房間特殊規則（dark／elite／hurry）。

網址加上 `?deck=all` 可以用全部 15 張卡作為牌組（測試用）；`?seed=數字` 可固定洗牌順序。

網址加上 `?quality=low`、`?quality=mid` 或 `?quality=high` 可以強制指定畫質。

## 本機執行

遊戲使用 ES modules，必須透過本機伺服器開啟，不能直接雙擊 `index.html`。

```
python -m http.server 8000
```

接著開啟 http://localhost:8000/

平板測試：電腦與平板連同一個 Wi-Fi，在平板瀏覽器開啟 `http://<電腦的區網 IP>:8000/`。
